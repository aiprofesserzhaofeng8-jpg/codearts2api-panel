# 用户费用与管理操作验收

日期：2026-11-02。

## 结论与改动

累计 USD 费用预算与账户余额是两个独立限制。费用上限控制累计消耗；余额控制剩余额度。一次实际费用同时增加累计费用并扣减一次余额，不存在因此重复扣余额的问题。但累计预算已用完时，余额充足也不能继续调用；补充余额不会重置累计费用。只需余额控制时，可把用户累计费用上限设为 0，其他配额仍独立生效。

用户列表改为「累计费用 / 上限（USD）」，编辑表单说明 0 不限；额度管理改为「当前余额」，显示有费用上限用户的当前累计和上限，并提示两者共同生效。没有更改现有用户的余额、预算或计费逻辑。

删除用户管理里的「用户登录入口」链接和空列表残留说明；「创建用户」移到卡片右侧。该链接原先只是跳转 `/user`，不存在一个同名的后端接口。普通用户继续共用 `/login` 和 `/auth/login`；旧 `/user/auth/*` 独立认证接口继续返回 404。
