# MobileClaw 首批接入验收

目标：把中国移动云 MobileClaw 作为上游账号加入本项目，不是配置 MobileClaw 访问本项目。

## 已实现

- 新增独立 `internal/mobileclaw` 适配器，复用账号、目录、调度、流式转换和额度显示链路。
- 个人免费 Token 通道，真实型号和 FREE 套餐交集；没有可用套餐不宣传付费模型。
- 身份核验同时检查令牌 uid 和上游 user-subjects；仅解码 JWT 不等同于认证，保存前仍必须请求上游校验。
- 官方客户端凭据导出助手、面板导入入口；导出仅包含访问令牌和必要账号/设备字段，不导出刷新令牌和机器指纹，不修改官方文件。
- 免费 Token 剩余量查询；`totalTokens` 语义尚未确认，不计算总额/已用。
- 保留工具、图片和原始 JSON 数字的传输，不执行智能体任务，不增加每请求目录查询或后台线程。

## 真实验证

本机官方 MobileClaw 1.9.8 登录态，固定官方域名，2026-11-13：
- 误将磁盘密文当作令牌时返回 401；内存解密后身份、目录、余额接口返回 200，不能把该 401 归因于账号无效。
- 首次缺少 `pkg-types` 的最小推理请求返回 500；按照官方引擎设置 FREE 后成功。
- 新 Go 适配器身份、目录、余额读取成功；`deepseek-v4.1-flash` 流式请求收到 `MC_ADAPTER_OK`，正常终止。
- 当前账号的免费目录查询曾返回 glm-5.3、glm-5.3-flash、deepseek-v4.1-flash；目录动态变化，不作为内置静态模型表。
- 未测真实图片/工具执行，不能把字段保留测试称为模型能力验证。未执行短信发送、二维码授权、续期、领奖、付费套餐调用。

## 自动检查与范围

适配器测试覆盖身份、套餐过滤、余额不误算、无热路径额外查询、JSON 大整数/图片字段传输、截断 SSE 拒绝。助手测试覆盖敏感字段排除、不覆盖已有文件、过期拒绝及私有文件权限。浏览器验收覆盖新平台仅导入入口、导出助手显示，以及现有账号列表、额度和主页面。

源码检查与浏览器验收使用隔离服务。未更新 `/opt/codearts2api`、未写入线上账号状态、未推送或发布新版本。

## 明确未完成

扫码/短信独立登录、自动续期、付费/企业套餐、奖励领取仍未实现。当前访问令牌过期后需在官方客户端续期并重新导入。此阶段不能称为 MobileClaw 全功能接入。
