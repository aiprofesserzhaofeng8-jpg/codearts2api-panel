# CodeArts2API 质量验收方案

版本：1.0，2026-10-26。范围：Linux、本机单进程、单管理员、多码道账号，DeepSeek V4.1 Flash 作为主要验证模型。本文先规定门槛，再执行验收；不将未观察完成的项目算作通过。

参考 [ISO/IEC 25010:2023](https://www.iso.org/standard/78176.html) 的九个产品质量维度，以及 [NIST SSDF](https://csrc.nist.gov/pubs/sp/800/218/final) 的安全开发实践。这是本项目的工程验收方案，不是 ISO 认证；24 小时、延迟和样本数等数值是项目自行规定的门槛。

## 判定与证据

每项记录编号、环境、执行时间、命令或操作、预期、实测、证据位置和状态：PASS（通过）、FAIL（失败）、PENDING（等待时间观察）、BLOCKED（缺少外部条件）、NA（范围外）。模拟测试、真实上游和客户端实际执行分别标明。

必选项全部 PASS，且没有未解决的严重缺陷，才能判定“本范围完整验收通过”。存在 FAIL / BLOCKED / PENDING 时，总结必须说明尚未通过完整验收。覆盖率、一次 HTTP 200、扫描未发现已知漏洞均不能代替其他项目。

发布阻断问题：管理鉴权绕过、实际密钥出现在可分发文件或日志、删除/更新丢失凭据、无限重试、重复输出、已知用量漏计、把截断摘要当作完整结果。范围外能力须明确拒绝并写入文档。

## 测试环境与控制

- 当前生产入口：`http://127.0.0.1:10087`，仅做管理只读、专用密钥真实调用和持续观察。
- 10088 为独立页面与配置测试实例，不改生产管理员密码、已有密钥或模型策略。
- 真实备用模型测试使用临时独立状态，借用仍有效的凭据快照；关闭自行续期、桌面回写和自动领取，避免与生产进程竞争轮转 refresh token。不让两进程共享状态文件。
- 真实请求使用单独测试密钥，限制次数和 Token / USD 参考预算；模型返回的未知用量单列。预算并非华为积分硬上限。
- 文本测试仅使用合成项目与随机文件标记，不上传用户的真实聊天记录。
- 验收报告不存密码、API key、STS、refresh token、授权码、完整客户端输出或私有对话；私有临时文件使用 0700 / 0600。
- 长时观察期间不做持续高负载付费压测：每分钟探活和进程采样，每 30 分钟一次极短生成，以覆盖凭据到期；费用记录实际用量。

| S01 | 信息安全 | 管理/API 权限隔离、CSRF、会话到期、改密、退出、DNS rebinding、重定向回归 | 所有边界用例拒绝越权；状态和列表不返回完整密钥 |
| S02 | 信息安全 | 用当前真实秘密逐值扫描可分发源码、文档及服务日志 | 没有匹配；报告只给文件/种类，绝不打印秘密 |
| S03 | 信息安全 | 对当前构建二进制运行 govulncheck | 没有命中的已知漏洞；记录工具、时间及二进制哈希；不等同于人工安全审计 |
| S04 | 信息安全 | 检查数据和私有测试文件权限、Web Storage 与 Cookie | data 目录 0700、秘密文件 0600；浏览器无保存的密码；Cookie HttpOnly / SameSite |
| M01 | 可维护性 | `go vet ./...`、构建、固定版 Sub2API 兼容测试 | vet/build 成功；上游固定测试通过；记录源代码与二进制指纹 |
| I01 | 交互能力 | usage / pricing / policies / style 浏览器回归 | 页面分离、分页、日期、编辑取消/失败、深浅主题和 390px 宽度正常，无 JS 错误 |

长时采样还要求最大采样间隔 ≤120 秒、样本数量达到每分钟一次的预期数量的 99%；机器休眠导致的大段观测缺失不能算通过。

长时内存门槛：去除前 10 分钟预热后，最后一小时 RSS 中位数不高于预热后第一小时中位数的 2 倍 + 32 MiB，且不得出现持续增长至进程失败；异常峰值另行解释。该门槛用于发现明显泄漏，不是严格内存泄漏证明。

## 范围外与补充项

- Windows / macOS、容器端到端、多实例共享状态、多用户组织、付款充值、真实华为积分硬限额、上游未声明的原生 Responses 能力：NA，不对外宣称已验收。
- 72 小时连续运行是后续增强观察，本轮最低要求为 24 小时；未到时不能提前写 PASS。
- 全新华为账号的交互式登录若需要用户完成认证，记录 BLOCKED 和已完成的模拟/入口测试，不绕过认证或替用户猜测凭据。
- 如 Codex 的本机工具沙箱不允许执行，只报告该环境阻断；不降低本机安全策略来掩盖兼容性结果。

## 复跑入口和证据

仅本地回归（不调用付费生成）：

```bash
python3 scripts/run-quality-acceptance.py
```

完整运行（会真实消耗码道额度，并启动 24 小时观察）：

```bash
python3 scripts/run-quality-acceptance.py --live
```

执行完的目录可继续汇总或补缺失的真实测试，不重复已经保留的证据：

```bash
python3 scripts/complete-quality-acceptance.py artifacts/acceptance/<本次UTC时间> --live
```

真实阶段的主密钥限制为 100 次 / 600000 Token / $0.50 参考估价；观察密钥限制为 60 次 / 20000 Token / $0.05。主验收密钥在短时验证完成后撤销，观察密钥在观察结束后清理。Token 包括缓存输入，USD 不代表实际华为积分。本次从 300000 Token 调整至 600000 的原因和保留计数记录见 test-budget-adjustment.json。

长时观察：`scripts/quality-soak.py`。报告生成：`scripts/render-quality-report.py`。观察任务的 systemd unit 名字写在本次 environment.json；`systemctl --user status <unit>` 可查看状态。当前这次预计在 2026-10-27 16:29（Asia/Shanghai）之后完成。

每次运行写入独立的 `artifacts/acceptance/<UTC 时间>/`，保留脱敏结果、测试输出及源指纹。仓库中的结果快照见 [QUALITY-SNAPSHOT.md](QUALITY-SNAPSHOT.md)。本机实时报告生成到 `docs/acceptance/QUALITY-REPORT.md`，不提交原始运行状态。持续观察完成后重新计算总判定；使用 `python3 scripts/export-quality-snapshot.py artifacts/acceptance/<本次UTC时间>` 导出可提交摘要。
