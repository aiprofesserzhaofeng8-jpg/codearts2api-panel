# 提示词独立页面验收

## 行为

侧栏增加「提示词」，原配置页提供跳转，不再编辑或提交提示词字段。
沿用公共默认值与八个平台的覆盖配置；旧继承关系、false、空文本和替换模式
保持。其余现有推理平台继续继承公共默认值。本批没有新增分组绑定或技能包安装。

处理方式明确区分透传、追加、替换。追加保留客户端规则；替换仍使用旧 custom
语义；追加留空不注入内置指令。三协议的预览复用实际处理函数，不访问上游。
预览通过 JSON 字符串传输，避免浏览器解析损失工具参数的大整数精度。

兼容策略集中在新页面折叠区。既有摘要豁免、恢复重试和原请求重建路径保持。
独立 API 比较提示词快照并原子保存，冲突返回 409；磁盘失败回滚，前端保留草稿。
运行设置 PATCH 在提交时保留未提交字段，防止覆盖并发保存的提示词。

## 验证

- 定向 Go 测试：追加保留系统/开发者指令、缓存块、签名、大整数，空追加不改变请求。
- 存储测试：旧独立值原样保留、保存重读、无关运行设置保留、过期快照拒绝与失败回滚。
- HTTP 测试：管理员权限、保存冲突、预览不写配置、非法协议拒绝。
- requestpolicy/config/storage/server 定向 race 通过。
- 前端单元测试：平台继承、旧替换模式、跨页草稿、失败保存与窄字段提交。
- product-settings-smoke.cjs：中英文、明暗主题、360px、三协议预览、独立保存、失败重试和重读。
- 浏览器截图已检查，位于 artifacts/prompts/（不入 Git）。

全仓检查发现此前 OpenCode 目录改造对旧账号放宽了协议范围；现已通过实际
