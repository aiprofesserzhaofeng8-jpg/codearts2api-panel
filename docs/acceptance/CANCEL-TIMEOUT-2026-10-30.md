**取消、超时与恢复验收 · 2026-10-30**

结论：三平台三协议的正常取消、请求超时和恢复链路可以释放上游连接、账号租约与密钥并发许可；发现并修复一处 WorkBuddy/Trae 的错误分类顺序问题。此次仅调整共享重试器中的取消检查位置，成功请求路径、原有总超时、尝试上限和逐事件转发不变。

**实际复现与最小修复**

两个 localhost HTTP 边界分别模拟客户端和上游，运行真实路由及各平台原生客户端。上游先发送 HTTP 401 或 429 响应头，再保持错误正文未结束；此时主动断开客户端，或使请求 deadline 到期。

旧代码在 WorkBuddy/Trae 返回 provider.Error 后，先调用 providerAccountError，再检查 context；8 个案例均把已经中断的请求继续分类：401 将账号计失败并冷却 300 秒，429 将模型计失败并冷却 60 秒。CodeArts 的 4 个相同对照因已有取消检查而通过。这说明跨平台取消处理存在不一致；不表示 HTTP 401/429 状态自身没有意义。

修复将 withAccountRetry 中已有的 context 检查前移到错误分类之前。请求已取消或总 deadline 已过期时，先解绑该失败请求的会话，并返回 context 原因，不继续判定凭据/模型故障或发起下一次尝试。CodeArts 既有取消解绑行为保留，WorkBuddy/Trae 对齐。账号租约继续由原有 defer 释放。

正常收到且完整处理的 401、429 仍使用原来的账号故障、模型冷却规则，4 个独立正向对照通过。没有修改凭据解析、账号池配置、请求预算或实际客户端默认参数。

**定向竞态验收：61/61 通过**

| 案例 | 数量 | 检查内容 |
|---|---:|---|
| 三平台 × 三协议 × 流式/非流式 × 主动取消/继承 deadline | 36 | 实际 socket 中断、首次输出不等待结束、部分内容保留、无成功终止伪造、一次上游尝试、失败日志、账号与模型不受罚、后续同密钥同模型立即恢复 |
| 三平台实际 RequestTimeout=1 秒 | 3 | 使用真实设置的总超时，结束后正常恢复 |
| 三平台 × 401/429 × 取消/deadline | 12 | 错误正文阻塞时取消不再触发账号或模型处罚 |
| 三平台 × 等待响应头时取消/deadline | 6 | 未收到上游响应头也能终止，下一请求恢复 |

每个中断案例都会实际发送第二个同密钥、同模型请求，要求立刻成功，并检查租约归零；密钥并发限制为 1，以发现并发许可泄漏。除了三个真实 1 秒设置案例，其余 deadline 通过隔离 HTTP 网关包装器继承 100ms context，缩短测试时间，没有修改生产超时值。定向运行启用 race，耗时约 7.5 秒；完整项目检查由本轮汇总验收记录。

**Sub2API 参考与取舍**

参考固定提交 a3298b46 的 [HTTP failover 入口](https://github.com/Wei-Shaw/sub2api/blob/a3298b46ebe239fb0720b068a1eb3383955bdac2/backend/internal/handler/openai_gateway_handler.go)：每次尝试前再次确认客户端仍在线，取消后不启动账号切换重放。该版本也明确将客户端正常断开与上游账号失败分开处理。这里借鉴取消与账号健康的边界，不复制其 WebSocket 路径或全部超时策略。

Sub2API 的部分流式路径通过 [detachStreamUpstreamContext](https://github.com/Wei-Shaw/sub2api/blob/a3298b46ebe239fb0720b068a1eb3383955bdac2/backend/internal/service/gateway_usage_billing.go) 在客户端断开后继续读取上游用量。本项目仍沿用取消即中断上游的策略，避免额外生成和长时间占用。最终 usage 未到达时继续记录为未知，不能将这种中断解释为没有积分消耗。

性能方面，本次取消逻辑位于错误分支，成功路径没有增加 JSON 解析、锁、分配、等待、写盘或上游请求。真实模型延迟与容量不由这些 localhost 数据证明；并发与性能对比单独验收。

本次没有调用真实模型、读取生产凭据或调整运行服务。证据：[旧版 8 例失败与 4 例对照](evidence/cancel-timeout-2026-10-30/baseline.log)、[修复后 61 例竞态测试](evidence/cancel-timeout-2026-10-30/fixed.log)、[结构化摘要](evidence/cancel-timeout-2026-10-30/summary.json)。
