## 交付

| 功能 | 最终行为 |
| --- | --- |
| 映射预设 | catalog 版本化 JSON，按当前目录、所选账号及白名单显式应用；保存后为普通固定绑定，不覆盖已有映射，不静默添加新来源 |
| 请求默认 | 仅缺省/空 model 使用分组默认；未知名称仍 404。Chat、Messages、Responses 一致生效，未设置时保留各接口旧行为 |
| 客户端偏好 | 独立于请求默认；模型列表和 client-profile 提供建议，启动器未写 --model 时采用，显式参数仍优先 |
| 显示/调用 | 逐模型独立开关；原始来源禁用影响所有引用映射，公开名禁用不自动禁止原始型号；原锁内复核，旧计划不能绕过刚生效的禁用 |
| 公共提示词 | 四字段逐项继承、平台覆盖，false/空字符串有效；旧配置保持独立，摘要豁免、搜索隔离及原有限重试保留 |

使用见 [分组模型](../GROUP-MODELS.md)、[提示词配置](../PROMPT-POLICY.md)。数据、默认和权限决策见 [ADR 0010](../adr/0010-product-model-and-prompt-policy.md)。API 契约与生成类型同步维护。

## 性能

同机 M5/M6、固定 CPU 0/2、GOMAXPROCS=2，交替 5 轮。21 项微基准中位数变化 **-2.70%～+3.45%**，没有超过 5% 的回退信号。覆盖选号、结算、普通/流式执行、恢复、大段输出与摘要。

9 个固定 20ms 上游的真实 socket 容量场景，共 90 条记录，均无失败、无残留租约，峰值并发符合 2。首轮一项摘要流式 P95 上升 5.11%，触发针对该项的 7 轮独立交替复测：P95 **-0.66%**、首内容 P95 **-1.96%**、吞吐 **-0.18%**，未观察到稳定退化。保留首轮信号，不以复测抹去原始数据。

可选规则的原子准入另测 3 轮、每轮 20 万次：0/79/512 条规则中位数分别约 **472/1005/3451 ns**。79 条规则的增加约 0.53 微秒，两次额外分配；该值是准入局部开销，不代表完整请求零成本。
