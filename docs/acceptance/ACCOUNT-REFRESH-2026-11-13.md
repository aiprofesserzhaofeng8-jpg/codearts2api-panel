# 账号列表刷新稳定性

参考本地 Sub2API checkout 的 AccountsView.vue/useTableLoader.ts：加载开始只设置 loading，数据在请求成功后替换，不清空旧列表。本项目仍由原 DOM controller 管理 v-once 子树，不引入第二套 Vue 状态。

修复两处重排来源：
- 额度刷新开始时保留已有快照，不用“查询中”替换完整额度内容。仅第一次没有数据时显示占位；真实新数据仍正常更新。
- 离屏构建 DocumentFragment，一次 replaceChildren 提交账号行；恢复表格的横纵滚动位置。筛选和翻页的主动回到顶部行为保留。

Qoder 隐藏内部套餐编码及冗余“已用”明细，余额、进度条和更新时间保留。

验证：accounts-table-smoke 延迟额度响应，检查请求中旧文字不变、表格高度和分页栏位置不变，响应后正常更新；等待首次入场动画/字体完成后测量。既有五组浏览器回归使用临时服务和假上游，不读取真实账号。

范围：解决账号页数据刷新引起的抖动；浏览器 F5 的首次加载仍需等待数据，不持久化账号或额度到 localStorage，也不掩盖真实数据变化导致的合理布局变化。
