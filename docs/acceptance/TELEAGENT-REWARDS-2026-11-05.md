# TeleAgent 每日积分验收（2026-11-05）

## 改动

TeleAgent 实现可选 `DailyRewards`，复用既有奖励锁、UTC+8 去重、等待期、持久化和余额缓存失效。单账号「每日签到」、批量领取、已开启的自动领取因此支持 TeleAgent，无新后台循环，无新凭据存储。

业务账号令牌与独立积分门户令牌分别使用对应域内路径和身份头；只调用明确的 `checkTask?type=daily_login`。领取前查可领状态，领取后必须确认 `claimed_today=true`；未确认、错误响应或限流不写今日已领，不污染推理健康。领取 GET 使用新 HTTP/1 连接，防止连接复用失败后透明重放。

奖励数量使用上游数据，未知不填零、不硬编码 100。收到上游活动展示信息时，按不可自动领取的活动提示投影。首登/月度赠送、邀请及其他条件奖励未纳入每日自动领取。

## 已验证

- 平台 race 测试：账号/门户两套认证、只读查询、已领幂等、缺字段/错误类型/负值/零值、隐藏任务、错误业务码、身份不符、提交成功但复查未确认、复查失败、429、取消、重定向阻断与精确 daily_login 参数。
- server race 集成：普通密钥不能领取、活动列表不触发领取、并发六次只提交一次、结果持久化和重开、旧余额失效后读到新余额、自动开关与停用账号、失败等待期及推理健康不变。
- 中英文浏览器测试：签到按钮、只读活动列表、其他活动不被领取、领取后余额和已领状态更新、自动领取设置包含 TeleAgent；原 TeleAgent 导入、WorkBuddy/Trae 入口和成长任务回归通过。

测试全部为隔离状态与模拟上游，没有实际领取用户账号的积分。当前官方账号资格和 v2 日常接口的真实服务端响应，仍需要账号侧验收。协议与活动分类见 [积分领取范围](../DAILY-REWARDS.md)。
