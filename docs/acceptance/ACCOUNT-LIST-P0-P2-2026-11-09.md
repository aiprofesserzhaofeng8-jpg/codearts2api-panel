# 账号管理列表 P0 / P1 / P2 验收

日期：2026-11-09。范围：管理端账号列表及原生 DOM 控制器。参考 Sub2API 的账号信息分层、用量组件和批量选择交互，复用本项目管理接口，没有复制它的调度或数据库实现。

## P0：显示信息准确

- 修正旧积分条与新用量窗口方向相反的问题：全部表示已用比例，80% 提醒、95% 警示，剩余另用文字表达。
- 未知值不按零显示；无总额不画比例；无限额度不显示耗尽；保留高精度余额字符串，不跨供应商合计积分。
- 列表最多两个窗口；超过两个时优先保留已耗尽窗口，其余通过详情查看。未展示的余额有提示。保留额度查询失败、重置已到期、更新时间。
- 状态列使用服务器账号池的可调度/暂停/停用/冷却/并发已满；缺少池状态显示待检查。额度快照不反向修改调度，不把某一窗口耗尽推断成所有模型不可用。
- 删除“自动续期已就绪”和重复“可续期”徽章，准确显示有/无/未知刷新凭据或无需续期。
- 最近错误和失败次数继续在列表可见；详情提供完整错误、凭据期限、奖励记录、全部额度窗口。

## P1：信息布局

- 默认七列：账号/平台、凭据、额度与用量、调度/并发、奖励、最近使用、操作。
- 来源合入账号信息；移除无辨识度的 AK“已保存”列；凭据列显示到期剩余时间，绝对时间可在详情查看。
- 操作集中为详情、探活、更多；查询到可领取时才显示领取快捷按钮。更多保留原有导出、并发、模型健康、启用/停用、暂停/恢复、清错、删除等功能。
- 支持名称、最近使用、即将过期排序，支持三个次要列显隐；本地持久化不含账号数据。核心列不能隐藏。
- 兼容中英文、移动端卡片，安全文本节点渲染，不改变 Vue/native 所有权边界。

## P2：明确范围的批量操作

- 当前筛选结果全选/逐项选择/清除选择；过滤掉的账号自动取消选择。确认窗口列出固定名单。
- 支持探活、额度刷新、奖励查询、领取可领奖励、暂停选号、恢复选号、解除冷却/清错和删除。
- 串行调用既有单账号接口，无新批量接口、额外后台任务、队列或自动重试；仅刷新额度时使用显式 `id` 的额度接口。
- 领取前查询，只有确认为可领才提交，不支持、已领或未确认时跳过。空 ID 不得退化成全部账号操作。
- 显示逐账号成功/失败/跳过结果；失败不伪装为成功。删除核对 `removed_id`。401/403 或登录生命周期结束停止后续请求。
- 执行期间禁止重复确认、关闭确认框及列表写操作。不会取消已经提交的写请求；操作完成后刷新已有快照。
- 批量启用/停用没有用 toggle 冒充幂等设置；本批通过暂停/恢复控制选号，原单账号启用/停用入口保留。
