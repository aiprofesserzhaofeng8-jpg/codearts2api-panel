# 全局统一模型 U5 验收

日期：2026-11-05。范围：[实施计划 U5](../architecture/UNIFIED-MODELS-PLAN.md#u5模型页与分组页)。结论：U5 已完成；下一项为 U6。源码未部署、未推送、未发布，未改用户 Pi/Codex 配置或生产数据。

## 交付结果

| 目标 | 实现与证据 |
| --- | --- |
| 一处维护统一关系 | 模型页新增创建、编辑、停用、删除、来源选择和公共策略；公开名称创建后只读，拒绝同平台/地区重复来源；新来源只从当前目录选择 |
| 缺失来源保留 | 已配置来源独立于目录选项保存，缺目录时标记并保留；刷新不会删除。编辑器展示账号数快照及时间，明确不是验证成功证明 |
| 分组授权 | 分组改为选择全局模型和账号，独立 visible/callable，展开 fixed/all 来源限制，保留默认模型、客户端偏好、原始白名单、规则及兼容模式；selected 空集禁止调用 |
| 撤下旧映射编辑 | 删除分组映射及应用预设按钮，读写规范 grant；分组 POST/DELETE 携带 revision，模型 CRUD 携带双 revision；管理状态返回规范组结构 |
| 策略和设置可保存 | 原始策略携带完整 ModelPolicy 和 routing revision，排除统一策略键；模型设置携带读取版本，保留脏草稿，提供明确重新读取，提交/重读时锁定控件 |
| 报告和定位 | 可本地读取迁移预检查 JSON，显示名称、组 ID、字段路径和原因；不上传报告、状态或凭据，明确报告只代表生成时配置；模型详情展示阻止删除的引用 |
| 显式来源测试 | 复用原测活端点，确认后测一个来源，展示完整 ID、文本成功/失败、时间；不声明图片/工具支持，不自动付费批量测活 |

普通用户、认证、后端权限和准入仍由原实现负责；前端读模型不构成权限缓存。没有新增服务或持久化表，schema 继续为 11。严格原始白名单补回搜索能力的既有命名空间校验，搜索能力不能绑定为统一对话来源。

## 页面与职责

- [统一模型组件](../../frontend/src/features/models/UnifiedModelsPanel.vue) 管理模型草稿、来源、公共参数与详情；原始目录、定价和原始策略保持独立。
- [分组组件](../../frontend/src/features/groups/GroupsPage.vue) 管理组表格与完整弹窗；[原控制器](../../frontend/src/features/groups/controller.js) 仅保留密钥/目录助手，避免两个渲染器管理相同节点。
- [共享配置投影](../../frontend/src/shared/unified-models.ts) 使用生成类型、稳定分页及版本一致性；表单从只读快照复制，刷新不会静默覆盖草稿。
- [接口客户端](../../frontend/src/api/client.ts) 保留数字状态及字符串 reason；同源 Cookie、取消读取和提交写操作的边界不变。
- [布局](../../frontend/src/styles/unified-models.css) 使用既有主题变量，覆盖桌面、390px 和 320px；新增文案有英文词条。

## 验收

新增 [6 个模型与分组前端用例](../../frontend/src/tests/unified-models.spec.ts)，覆盖分页版本变化不发布半份清单、本地报告拒绝状态文件、模型冲突保留草稿、selected 空集的严格写入、错误 reason 及未确认保存回执；另加 [设置重读回归](../../frontend/src/app/bootstrap.spec.ts)，确认明确丢弃草稿时清除未保存的密码。前端总计 52 项测试通过。

[真实接口浏览器用例](../../backend/internal/app/unified_ui_test.go) 在临时 Store 和真实 app.Build/Handler 上运行 [浏览器脚本](../../scripts/unified-models-smoke.cjs)，平台适配器为进程内模拟，认证、校验、CAS 和落盘不拦截。另以读取空目录及拒绝写入的响应验证 UI 故障处理。完成浏览器流程后重新 Open 状态，检查全局定义、两个来源、禁用状态、组固定授权及客户端偏好均持久化。

已通过：创建双来源模型、文本测活、固定来源授权、两个默认值、禁用来源、刷新保留、模型及分组并发冲突/草稿保留/明确重读、目录缺失保留、403 拒绝、空目录、原始策略版本写入、设置版本写入与密码草稿丢弃、桌面/手机/主题和报告安全文本显示。

既有 26 项浏览器回归全部通过。首轮 23 项通过，修正旧夹具的设置读取、分组折叠区交互及测试固定端口冲突后，重跑其余 3 项通过；结果合并按用例保留最新一次，不把初次失败记作通过。连接组件测试仅将本测试浏览器请求转发到临时模拟端口，没有停止或占用用户的真实连接组件。

## 剩余边界

来源测试为模拟平台，未消耗真实额度，不代表真实跨平台可用。完整协议/计量/故障恢复综合验收、Pi 实际客户端闭环、安装包及升级恢复属于 U6。原探测服务没有完整结构化历史，来源 last_probe 仍为 null；页面内显示的文本测活结果不冒充持久化历史。

当前运行实例仍使用原二进制和数据；本阶段只交付源码、隔离构建及验收材料。
