## 已修复

1. MobileClaw 的内部传输总是 SSE，却未统一请求 `stream_options.include_usage=true`。显式请求用量并保留其他 stream_options，减少非流式客户端请求缺少计量回执的问题；不伪造缺失用量。此修复不是已证实的 HTTP 400 根因。
2. 真实验收脚本过去仅以 chat_text 通过决定退出 0，图片/工具失败也可能报整体成功；且不含 chat_text 的功能子集会 KeyError。现在所有选定功能必须 PASS，缺失/BLOCKED/FAIL/ERROR 都不能整体成功；新增请求预算与可跳过接口探测参数，纳入 make check。
3. MobileClaw/Qoder 非 200 响应只显示 HTTP 状态，缺少结构化业务码。读取最多 16KiB JSON，只保留受限数字/大写业务码及原 Retry-After，不返回任意上游消息、URL、请求正文、凭据。不推断未知 403 的重试策略，不改全局权限规则。
