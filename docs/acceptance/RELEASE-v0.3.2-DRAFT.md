# v0.3.2 发布说明草稿

本版本将本地单实例多用户改造与部署工具交付到正式版本：统一管理员/用户登录、首次安装向导、用户额度及分组权限，以及可校验的安装、备份恢复、升级和源码实例迁移流程。

管理员可在“配置 → 版本与更新”查看实际运行版本并检查新版本；服务器使用 `install.sh` 选择、下载和校验发布包。操作指南见 `deploy/README.md`。

## 附件

- `codearts2api-panel-v0.3.2-linux-amd64.tar.gz`
- `codearts2api-panel-v0.3.2-linux-arm64.tar.gz`
- `panelctl.py`
- `install.sh`
- `SHA256SUMS`

安装包使用独立受管目录；不覆盖既有部署。升级与源码迁移自动执行范围仅限相同 schema。当前 schema 为 10，旧公开版本的状态跨版本迁移需要单独验证，不能使用旧程序打开新数据。完整备份含账号凭据，应保存在私有目录；失败不会自动用旧备份覆盖新凭据或账本。

验证包括完整应用检查、部署单元测试、权限与并发测试、浏览器版本卡片、真实用户级 systemd 安装/升级/迁移及本地 HTTPS 流式验收。ARM 包仅交叉编译；公网证书与云服务器部署不在本次验收范围。

发布范围说明：本轮开始时本地 develop 已比远程 main/develop 多 35 个既有提交。正式发布将同时包含这些已开发功能，不只是新增安装脚本。v0.3.1 为交付候选，云端普通 CI 发现既有预设文件格式问题；v0.3.2 补齐格式检查后重新发布，不移动旧标签。本文件在发布前为草稿。
