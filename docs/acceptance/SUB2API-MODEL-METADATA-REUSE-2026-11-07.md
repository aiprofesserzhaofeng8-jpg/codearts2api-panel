# Sub2API 模型参数复用验收

日期：2026-11-07。范围：R6 后续参数补缺与客户端配置生成。源码目录 `/home/white/codearts2api-panel`；当前系统服务仍是原进程，未部署本次修改，未修改现用 Pi 配置。

## 复用内容

从 Sub2API 固定版本 `6b4b37db43443b5e88e424fe3c69602cc3810dfb` 的 `backend/internal/service/upstream_models.go` 直接提取 6 个结构体和 6 个纯函数，放在 `backend/internal/catalog/modelmeta`。其中包括只填缺项的元数据合并、models.dev 数据转换，以及转换依赖的规格归一化。提取函数与结构体的 SHA-256 已逐项核对；来源、许可、提取清单见 [UPSTREAM.md](../../backend/internal/catalog/modelmeta/UPSTREAM.md) 和 [upstream.json](../../backend/internal/catalog/modelmeta/upstream.json)。

账号、凭据、权限、选号、重试、计量继续使用当前实现。参数库只接入现有目录刷新与 ModelPolicies；公开资料不是第二份可用模型清单。

## 最终行为

数值参数按以下顺序使用：已保存策略 → 上游目录 → 精确来源实测建议 → 精确原生 ID 的公开资料 → 兼容默认模板。缺项逐字段补充，已有上游限制不被回退值覆盖；明确小于客户端可表达范围的上游数值仍不给出更大的假上限。

保留现有 GLM-5.3-Flash 等来源的 32768 / 4096 实测操作建议。一般缺参聊天入口使用 32768 上下文 / 4096 输出的模板，并标为 `compatibility_default`；公开资料标为 `public_registry`。模板与公开资料都不是平台实测最大值。Sub2API 的 272000 通用 Codex 上下文未直接用于这些非 Codex 平台。

models.dev 的请求只在原串行目录刷新中执行：固定 HTTPS 地址、无凭据、无对话或模型清单，8 MiB 上限、5 秒截止、成功缓存 6 小时、失败退避 30 分钟。网络或解析失败保留旧资料，并允许缺参模板继续工作；没有新增后台循环、状态文件或数据库。普通推理不查询公开站点。

精确 ID 使用既有已审核的命名映射；没有通过模糊匹配推断内部槽位。Qoder 已审核槽位改名后不能继续充当原共享型号；显式原始槽位可以获得标为默认值的客户端模板。缺失目录占位行不能获得新默认参数，已有显式来源策略保持原有兼容。新参考数值纳入默认目录预览指纹，刷新后不能用旧预览静默保存已变化的建议。

共享名称继续按全部授权来源生成保守公共参数；公开接口保留聚合证据并隐藏精确来源，管理员详情保留来源依据。图片、工具和原生能力约束保持独立；公共资料中的 modality/reasoning 字段不会被用来授予平台能力。专用补全、跳转、重写、生图、摘要和用途未确认入口继续按原用途规则处理。
