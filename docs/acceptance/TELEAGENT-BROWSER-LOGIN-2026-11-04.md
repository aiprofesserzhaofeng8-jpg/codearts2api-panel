# TeleAgent 浏览器登录助手验收（2026-11-04）

后续自动交接范围见 [2026-11-05 连接组件验收](TELEAGENT-CONNECTOR-2026-11-05.md)。

## 范围与使用

在已有 TeleAgent 适配上增加「添加账号 → TeleAgent → 浏览器登录」。面板生成十分钟任务，提供与当前前端版本一致的独立 Node.js 助手下载；用户在自己电脑运行助手，在新开的官方页面登录，选择生成的结果文件，再检查身份、确认保存。适用于本地和远程面板，不在服务器运行桌面浏览器，不增加公开上传或免认证回调。

助手默认自动检查固定安装位置，读取官方客户端的 NewApi 网关配置、真实版本和设备级 device-meta.json，手工配置只作为 --config 兼容参数。只取四项元数据，不读取旧 Token、身份、门户 Cookie 或运行中的桌面/浏览器。账号密码和验证码仅在官方页面输入，结果文件含新的 Token，需妥善保管并在确认后删除。没有已确认的自动续期协议。

## 边界与验证

- 平台实现沿用 `BrowserLogin / CallbackLogin / LoginReleaser`，中立服务只透传可选任务绑定。随机任务保存在已有十分钟/128 项范围中；检查执行只读身份验证，不写账号池，确认保存仍由 Store 唯一提交。
- Go race 回归涵盖任务不匹配、无效/过期/取消、上游身份不一致、并发重复检查、结果不可更换、检查期间取消、重试预览、显式重复账号覆盖及保存幂等。管理接口预览不返回令牌、网关密钥或设备信息，普通调用密钥不能开始授权。
- Node 标准库 13 项测试覆盖 ASAR 索引/偏移/截断/非 TeleAgent 程序拒绝、NewApi 签名通道选择、真实版本、固定路径与缺客户端/设备、空路径分类，以及固定官方地址及有效期、仅选择四项客户端信息、租户前缀、排除 UPMS/统计/过期令牌、准确回调主机/路径、重定向及 Base64 正文、取消、CDP 响应分发、0600 独占写入和拒绝覆盖。
- 实际 Chromium 的 CDP 回归使用截获的模拟官方响应，验证正文和 302 深链的授权结果捕获、原始租户前缀及取消监听清理。单独启动助手自己的 Chromium 进程，阻断官方主机 DNS，验证随机 loopback 调试端口、取消后浏览器退出及临时 profile 删除；没有关闭浏览器沙箱。
- 页面回归覆盖中英文、手机 390px、助手下载字节与源文件一致、无凭据的任务文件、旧任务不能复用、读取文件不自动提交、身份拒绝后重试、核对预览、确认保存和取消后敏感值清空。
- 前端 45 项单元测试通过；`make check` 的完整 Go 测试、vet、架构/接口类型、HTML/CSP、86 项部署工具及数据兼容检查通过。完整 24 项浏览器回归全部通过，结果位于忽略目录 `artifacts/teleagent-login-e2e/browser-results.json`。
