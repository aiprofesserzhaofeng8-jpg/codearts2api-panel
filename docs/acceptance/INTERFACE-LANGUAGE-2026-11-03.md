# 界面语言验收

日期：2026-11-03。范围：中文/英文自动检测、手动选择持久化、共用右上角菜单。设计见 [ADR 0016](../adr/0016-interface-language.md)。

## 已实施

- 手动中文/英文优先；跟随系统按浏览器语言顺序识别，无支持语言默认中文。跟随系统不把检测结果固化为手动选择。
- 加载时统一确定语言；轮询、切页、存储事件和浏览器语言事件不改变已挂载页面。选择先保存再刷新；本地存储受限时使用当前标签页会话存储，无法保存时显示错误。
- 管理员、普通用户、登录和安装页共用语言菜单；支持键盘与焦点返回。已提交 API 写入期间禁用切换。
- 静态模板、原生控制器和用户页面显式翻译，日期/数字跟随界面 locale。导航使用稳定 ID。模型 ID、中文分组名、用户输入与请求参数保持原值。
- 320px 窄屏收紧语言按钮间距，并隐藏冗余的用户头像，使语言、主题与退出按钮互不遮挡。390px 和桌面保留原有身份展示。

## 验证

环境：Linux amd64、Go 1.27.3、Node 24.11.0、pnpm 10.34.9、Chrome headless。全部常规验收使用临时状态及模拟接口。

| 检查 | 结果 |
| --- | --- |
| `make check build`（使用固定 Go 路径） | 通过：前端构建、类型、Go test/vet、资源/CSP、架构和部署工具检查 |
| `./scripts/frontend.sh check` | 8 个文件、37 个测试通过，包含语言优先级、存储失败、事件稳定性、菜单键盘和在途写保护 |
| `scripts/frontend_e2e.py` | 16 项通过：三平台表单、分组、成长交互、用户/权益、统一控制台、样式及语言切换 |
| `scripts/setup_e2e.py` | 首次安装、重启恢复与角色隔离通过；新增英文检测、中文手动选择及刷新持久化通过 |
| 最终资源与发布包复核 | `check_html_js.py` 通过；从最终包提取程序，重新执行 unified-console、user-style、i18n 三项，全部通过 |
| 截图检查 | 英文桌面，以及管理员/普通用户 390px、320px 语言菜单正常；控件不重叠、菜单不超出窗口 |

`i18n-smoke` 使用实际隔离 HTTP/认证，覆盖英文浏览器首次加载、中文偏好跨刷新、英文偏好在中文浏览器中优先、恢复自动、法语回退中文、9 个管理员页签和 8 个用户页面、中文分组名保持、路由刷新、普通用户不请求管理接口、本地存储受限与完全禁用。浏览器无页面异常或 CSP 错误，没有真实模型调用或奖励领取。

本机 10088 受管服务已使用本地构建的 v0.3.6 包升级。升级工具完成停机备份、版本切换、启动及健康检查；升级前后状态字段完全一致。已核对实际 PID、程序 SHA-256 与最终测试程序一致，并在该服务的登录页重新验证自动英文、手动中文多次刷新保留和恢复跟随系统。本机验收时尚未发布对应的 GitHub Release。

## 限制

语言偏好属于当前浏览器；会话存储回退只保证当前标签页跨刷新。手动切换会刷新，未保存草稿需要先保存。后台返回的错误、上游活动内容和用户数据可能保留原语言；本批没有服务端国际化或真实上游协议验收。
