# 目录刷新、缓存与模型测活分离验收（M3 第十五批）

日期：2026-11-01。基线 `c1f2382`，版本 `0.3.0-structure-m3.15`。M3 尚未整体完成。

## 改动与边界

`catalog.Runtime` 接管模型目录刷新编排、刷新状态缓存和有界模型测活。app 注入同一 Store 与 Registry，Registry 继续作为唯一清单和解析方；不建立第二份目录、别名缓存或账号运行状态。原刷新串行锁、刷新状态读写锁、测活任务锁分别随所属业务移动，不合并、不扩大锁域。

HTTP 保留管理员守卫、宽松 JSON 解码、方法行为、状态码、响应和取得测活任务锁的时点。CodeArts 凭据读取、模型清单获取和原生 Probe 由 `upstream/codearts` 包装，借用同一 Manager/Client；WorkBuddy/Trae 的模型清单仍走原凭据与适配器，测活仍调用原 chatOnce。不新增凭据编解码、网络轮次、普通推理调用、准入或计量入口。

目录按平台/地区刷新，失败继续尝试同分区账号、成功后跳过其余账号；失败保留旧分区，部分成功与错误展示保留原规则。CodeArts 空清单属于错误；通用目录操作仍接受成功空结果，但各平台适配器可自行拒绝空清单。stale 刷新仍同步执行，使用独立 30s Context，失败与成功均缓存时间；管理员刷新仍保留 60s 上限。

测活仍最多 64 个去重型号、4 路模型并发，逐型号按账号顺序尝试，每次账号尝试 30s。CodeArts 原生 Probe 使用原 `max_tokens=8`，其他平台仍走原 `max_tokens=64`；取消、结果顺序、没有匹配账号的结果字段、失败后换号成功仍可能保留旧 error 字段等行为均未调整。明确指定停用账号及原宽松解码等历史语义也保留，不将它们作为本次结构迁移修复项。

同一 HTTP 契约测试编译到私有冻结基线与当前代码，38 项目录/测活响应与上游调用记录全部一致；另重跑 62 项配置 HTTP/落盘对照，全部一致。覆盖刷新成功/失败/恢复、空清单、缓存命中、平台地区、单账号/未知账号、去重/空值/上限、取消、宽松解码和原方法行为。所有上游由内存假 transport 或本机假服务应答，无真实凭据；临时基线已删除。

七组页面检查通过，其中既有 groups 脚本覆盖模型搜索/分组筛选/刷新、筛选后的测活参数、空列表与移动端主题；新增批次不改页面文件。配置页实际 HTTP 保存、重载与登录失效回归通过。二进制独立 cwd 登录、资源逐字节校验与重启恢复通过；Docker UID 10001 下登录、资源和重启通过。Windows 未实际运行。

AST 核对 Store 的 114 个函数体、其余 262 个 server 函数体和去重函数保持原内容；普通推理、gateway、protocol、requestpolicy、accounts、access、config、registry 和原生三平台文件逐字节不变。CodeArts 适配目录仅新增薄包装，既有文件不改。schema、权限、调度、预算和账本仍走原实现。

## 真实平台验证

关闭副本自动刷新、导入/IDE 回写和领奖，共完成 15 项真实检查、17 次客户端生成请求：三平台各流式/非流式，三组工具调用及回填，CodeArts 显式非流式与 Pi 流式摘要，以及三平台各一次单型号测活。两种摘要均一次完成且 `finish_reason=stop`。普通请求核对统一名、实际型号与真实用量；实际型号分别是 `deepseek-v4.1-flash`、`workbuddy/cn/deepseek-v4.1-flash`、`trae/cn/deepseek-v4.1-flash`。

显式管理刷新成功返回 83 个模型且 `provider_errors` 为空。三次测活分别指定同平台账号和物理型号，结果均可用。副本凭据未轮转、最终租约为 0，临时状态已删除，共享状态未由真实验收修改。本批没有真实续期、领奖或成长执行；凭据在验收时有效，不据此保证未来自动续期。

## 性能

构建、浏览器、真实验收和竞态检查结束后，同机 CPU 0/2、GOMAXPROCS=2 下旧、新测试二进制交替五轮。容量共 90 条记录、9 类场景，失败和残留租约为 0，峰值并发保持 2，上游调用次数保持原 40/80，CodeArts 普通场景为 100 样本。p95 中位数变化 **-1.81% 至 +1.72%**。

18 组微基准在 `/dev/shm` 临时夹具下完成，涵盖普通执行、统一名、计时、长响应、摘要/重试和本批额外加入的缓存模型列表。ns/op 中位数变化 **-1.37% 至 +3.09%**。其中 `/v1/models` 缓存命中为 **7752 → 7749 ns/op（-0.04%）**，分配数为 **77 → 77 allocs/op**。

本轮未触发超过 5% 耗时增长的复核阈值，未观察到稳定性能退化。负值不作为优化收益声明；生产持久化不变，假上游结果不能保证真实网络和平台延迟恒定。全部绝对耗时、分配与样本见 [机器可读记录](STRUCTURE-M3-15-2026-11-01.json)。
