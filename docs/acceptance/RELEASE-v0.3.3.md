# v0.3.3

本版本提供统一管理员/用户登录、管理员首次安装向导、用户额度与分组权限，以及 Linux 单实例的安装、备份恢复、升级和源码实例迁移。

- 管理员在“配置 → 版本与更新”查看实际运行版本、检查正式更新并访问发布说明。
- `install.sh` 支持选择稳定版本、下载及校验程序和运维工具，再执行安装或升级；`panelctl.py` 统一处理数据备份与版本切换。
- 发布包包含 Linux amd64/arm64 二进制、部署模板和许可；独立 `install.sh`、`panelctl.py` 与 `SHA256SUMS` 一并提供。
- 固定版本容器镜像提供健康检查，Caddy 模板支持 HTTPS 和 SSE。前端在构建机原生架构测试和生成，Go 交叉编译为目标架构。

首次安装固定管理员用户名 `admin`，通过服务器私有安装凭证进入向导设置密码，无通用默认密码；普通用户由管理员创建。

当前状态 schema 为 10。受管自动升级和源码迁移仅接受相同 schema；旧公开版本的数据跨 schema 迁移需要单独验证。恢复写入新目录，不自动覆盖最新凭据或账本。备份含账号凭据，应私有保存。

安装、容器、域名、备份恢复、升级与排障见 [部署指南](https://github.com/aiprofesserzhaofeng8-jpg/codearts2api-panel/blob/v0.3.3/deploy/README.md)。网页只检查更新，服务器通过部署工具执行升级。

验证覆盖 Go/前端/部署检查、权限与并发、真实用户级 systemd 安装升级迁移、非空账本恢复和本地 HTTPS/SSE。ARM 二进制仅交叉编译；公网证书与云服务器未在本轮验证。
