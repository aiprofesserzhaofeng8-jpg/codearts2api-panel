## 结构与性能边界

相对 M3，**180 个既有生产 Go 文件逐字节不变**。`server.go` 只改静态资源路由；`web.go` 只切换嵌入资源与资源响应，新增 `webui`。推理、搜索、重试、提示词、选号/租约、凭据、计费、账本及持久化逻辑未改，也没有新增上游请求或锁。

CSS 源码、主题脚本和图标与旧版逐字节相同；两段 Trae 授权原始命令保持原文。未引入推理链路性能变更，因此不重复执行真实上游对照，不根据页面测试推断模型响应速度。

首屏未压缩 HTML + CSS + JS 合计由 **278,350 B 增至 295,991 B**，增加 **17,641 B（6.34%）**，不计图标和 HTTP 头。Vue 运行时和组件代码增加了 JS，HTML 与 CSS 构建后减少；不能只比较 JS，也不能称为零开销。生产维持原 `no-store`，未借重构改变缓存策略。固定假数据的本机页面就绪测试未发现持续等待问题，但样本少、无网络限速，不作为公网加载速度承诺。
