**非法 JSON：真实 HTTP 链路独立复测 · 2026-10-29**

结论：本次重新执行的模拟测试确认，修复后的 CodeArts 非流式路径可以识别 HTTP 200 中的非法 JSON，不再将这些响应记为成功。没有使用此前的测试结果代替本次执行。

测试通过两个独立的 localhost HTTP 服务构成“HTTP 客户端 → 网关 Handler → 模拟上游”。只把上游地址指向本机，保留生产 JSON 校验、实际退避等待、重试上限、响应写出及日志统计。账号与凭据均为夹具，状态保存在临时目录，没有修改生产设置或消耗真实上游额度。新增测试位于 `internal/server/nonjson_http_test.go`。


错误正文不会泄漏模拟上游的原始内容。每个案例还断言日志状态与尝试次数准确、账号保持健康、在途租约归零。单账号重试案例只在测试状态中关闭模型冷却以便重复选择同一夹具账号，仍保留真实退避：失败后恢复约 1.006 秒，连续三次失败约 3.016 秒，符合原有 1 秒、2 秒等待。普通异常案例设置最多尝试一次以单独检查错误转换。这些时间包含竞态检测开销，不用于性能对比。

本次同时重跑原有 24 个定向案例，其中包含模型冷却后换不同账号、输出提交前完成重试、合法扩展字段保留，以及三个客户端协议的异常响应检查。共 34 个案例通过竞态检测。
