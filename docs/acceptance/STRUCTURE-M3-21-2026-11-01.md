## 改动与边界

- `accounts.Probes` 接管管理探活的串行循环、超时、目录更新和结果保存；CodeArts 会话/最小请求留在 `upstream/codearts`，HTTP 保留宽松解码与 wire DTO。
- 保留停用/暂停账号参与探活、显式 ID 不修剪、未知账号返回空列表、30/60 秒截止时间、原生先失效再解析、目录成功才发布、取消后写结果、批尾保存失败仅记日志。失败时已有会话的脱敏 AK/有效期仍返回。
- `config.ModelPolicies` 接管实时管理员策略优先与上游目录保守推荐；`CommonModelPolicy` 接管统一型号公共建议，按来源顺序读取、遇缺失立即停止。模型别名、映射授权、路由、能力与产品规则未修改。
- `make architecture` 与 CI 使用 `go list -json` 检查生产直接导入，另有 3 项检查器测试。禁止业务反向导入 HTTP/Store/具体平台以及平台互相导入，不以文件数或行数作为约束。Registry/apierr/Store 的旧原生桥接仍明确保留。
- 无新锁、缓存、协程、网络重试或配置字段。Store 的准入/CAS/账本/保存与三平台原生协议、网关推理、页面、CLI 均保留；推荐计算 AST 与旧实现一致。
