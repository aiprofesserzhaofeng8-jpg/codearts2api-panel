# 分组与 API 密钥管理分离验收（M3 第十三批）

日期：2026-11-01。基线 `107b0d3`，版本 `0.3.0-structure-m3.13`。M3 尚未整体完成。

## 改动与边界

`access.Management` 接管分组保存前的目录归一化、缺省映射兼容、密钥创建和引用解析、删除/启停、分组绑定及预算配置协调。app 借用同一原始目录和当前别名，不增加注册表、权限副本、缓存或锁。HTTP 继续负责管理员认证、DTO、参数大小、脱敏和状态码；密钥明文找回仍只在管理员守卫之后执行。

`APIKey`、`AccountGroup`、`ModelMapping`、`KeyBudget`、`BudgetUsage` 的规范定义迁入 access，Store 保留类型别名。AST 核对五种类型的字段、顺序和 JSON 标签一致，Store 的 118 个函数体以及其余 266 个 server 函数体未变。原始型号白名单、账号范围、权限发布、预算预留/重置、准入锁和账本保持原实现；普通推理、平台原生协议、gateway、protocol、requestpolicy 和页面文件逐字节不变。

兼容行为保持原值：更新分组时省略/null 映射继承旧值，显式空列表清除；映射来源必须精确命中原始目录，白名单沿用别名归一化及未知型号保留。密钥引用支持原值、稳定 hash 和旧脱敏值，旧脱敏碰撞仍按首个匹配处理。分组/绑定/预算等严格保存失败回滚；旧版密钥删除/启停的保存失败继续只记日志、保留内存改动。本批不借重构调整这些历史语义。

## 验证

`make check`、全量 `go test -race -count=1 ./...`、Windows vet/交叉构建、启动器 9 项和 Pi 回归通过。新增 app 装配测试验证当前目录/别名更新、映射缺省与清空、保存失败后权限快照和磁盘一致、在途预算重置拒绝，以及旧删除/启停保存失败后的恢复。

冻结的旧、新二进制以隔离假账号运行 54 项 HTTP/落盘对照，全部一致：映射来源/白名单/账号/名称校验、省略/null/空列表、密钥创建/停启/绑定/预算/删除、原值/hash/脱敏引用、脱敏碰撞、方法/参数错误及非管理员拒绝。假凭据的上游网络被代理阻断；随机 ID、密钥及创建时间按角色归一后比较，不能视为真实平台结果。

既有 providers、trae、trae-device、groups、account-create、growth-multi 六组页面测试通过。另以真实本地 HTTP 管理接口完成分组/映射创建、分组密钥创建、预算保存与重载、模型菜单权限、停启、解绑和删除；全密钥复制/显示/隐藏/重载/剪贴板回退通过，无明文密钥进入日志或截图。二进制在独立 cwd 下登录、资源逐字节校验与重启恢复通过；Docker UID 10001，登录、资源和重启通过。Windows 未运行。

## 性能

重负载、构建和浏览器验收结束后，在同机 CPU 0/2、GOMAXPROCS=2 条件下，冻结旧、新测试二进制交替五轮。容量记录 90 条、9 类场景，失败和残留租约为 0、上游并发峰值为 2；调用次数保持 40/80，CodeArts 普通容量样本为 100。各场景 p95 中位数变化 **-3.90% 至 +1.75%**。

17 组微基准涵盖普通三平台、统一名响应、关键计时、1 KiB/1 MiB 摘要及截断重试，五轮 ns/op 中位数变化 **-1.79% 至 +6.08%**。其中未修改的统一名响应处理初测 2384 → 2529 ns/op（+6.08%，20 次分配不变）触发复核；将该项从每轮 2000 次延长至 20000 次、交替七轮，结果为 2413 → 2430 ns/op（**+0.70%**），928 B/op、20 allocs/op 相同。该项初次信号未在长样本中复现，未通过改代码消除测量波动，原始五轮结果完整保留。

临时存储固定在 `/dev/shm`，生产持久化不变；绝对耗时、分配数、初次及复核样本见 [机器可读记录](STRUCTURE-M3-13-2026-11-01.json)。本轮未观察到稳定性能退化；这些假上游结果不能保证真实平台延迟恒定。
