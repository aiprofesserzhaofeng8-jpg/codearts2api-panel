# 账号管理布局与活动福利折叠

参考本地 Sub2API `ba81c7f` 的 `frontend/src/components/layout/TablePageLayout.vue`：操作和筛选固定，表格占用剩余高度并内部滚动，手机恢复自然页面滚动。

## 本次行为

- 宽度至少 1024px、高度至少 640px 时，账号页限定为当前视口的可用高度。账号增多、筛选为空或出现批量操作栏均不增加外层页面高度。
- 表格可键盘聚焦和滚动，表头与底部账号计数固定；右侧操作列继续固定。
- 活动福利变为默认折叠的一栏，支持鼠标和键盘展开。展开不触发查询或领取；原账号选择、查询、领取、邀请入口保留。
- 展开的活动区在桌面有最大高度和内部滚动范围；手机或低矮窗口使用自然滚动，避免控件挤占整个表格。
- 额度直接展示，额度详情入口与弹窗继续保持删除状态。没有新增接口、持久化字段、后台任务或轮询。

## 验证

`accounts-table-smoke` 使用合成账号验证 0、3、43 个账号的固定高度、末行可滚动到达、表头与计数位置不变、福利默认折叠和键盘展开、1280×720 窗口与手机适配，并保留中英文、明暗主题、批量部分失败与删除回执检查。

`teleagent-rewards-smoke` 展开福利栏后完成模拟查询和领奖；`quota-smoke`、`account-create-smoke` 验证额度与账号添加。所有回归使用临时状态和模拟上游。

源码测试、候选安装包验证与系统服务更新是不同步骤。系统服务仍需本机 sudo 授权，准备安装包不代表已替换运行版本。
