# 账号页更多操作与分页

参考本地 Sub2API `ba81c7f` 的 `AccountsView.vue` 工具菜单与 `components/common/Pagination.vue`，复用本项目现有账号接口和原生 DOM 控制器。

## 行为

- 右上角“更多操作”分为数据操作、工具、列显示。导入进入原账号向导并选中凭据导入；导出要求恰好勾选一个当前页账号，使用原导出接口。全部探活、活动领奖沿用现有流程。
- 菜单在浏览器顶层显示，不受固定高度表格裁剪。点击外部或 Escape 关闭，支持方向键切换焦点。切换显示列不关闭菜单；勾选、名称与操作列始终保留。
- 数据先筛选、排序，再本地分页，默认 20 条，支持 10/20/50/100 条。底部提供结果范围、每页条数、前后页与页码。大页数以省略号展示。
- 筛选和排序变化回首页；删除或刷新造成当前页越界时自动收回到有效页；空列表为 0 至 0，前后页禁用。
- 勾选仅针对本页。翻页或调整每页条数清空勾选，批量操作确认窗口固定目标 ID。执行期间禁止翻页，不新增任何批量写接口。
- 每页条数和列显示复用现有浏览器偏好，不保存账号内容。未新增后台定时任务、轮询或分页 API。

## 验证范围

- 单元测试覆盖首末页、删除后页码收缩、空结果、条数校验及大量页码的省略显示。
- 浏览器使用 43 个合成账号验证 20/20/3 翻页、10/50 条切换与持久化、筛选回首页、跨页清除选择，以及第二页勾选两条后请求只包含这两个 ID。
- 验证菜单内导入、所选账号导出、列显示持久化、Escape/外部点击关闭与手机菜单边界。
- 保留固定高度、福利折叠、额度、奖励、账号添加和页面导航回归。全部使用临时状态和模拟上游。
