# TeleAgent 自动登录交接验收（2026-11-05）

## 已实现

主流程改为浏览器登录 → 官方认证 → 自动核对身份并显示账号预览 → 确认保存。第一次下载并安装本机组件、填写连接码；后续无需终端、任务文件或结果文件。文件模式只保留在折叠高级选项。

组件仅监听 `127.0.0.1:18765`，绑定明确面板 Origin 和随机连接密钥；浏览器直接读取本次结果，并使用原管理员认证接口提交验证。组件没有管理员 Cookie，后端未增加公网回调或免认证账号写入接口。正常结果保存在内存，确认前仍不入库。

Linux 采用用户桌面 autostart，Windows 采用 Startup VBS（无需命令 Shell）；首次仍要求 Node.js 22.15+。macOS 目前只能前台 `--serve`。组件安装、更新、停止和卸载仅操作本机组件路径，不修改官方客户端或面板数据。

## 验证

- Node 16 项单元/HTTP 集成测试：固定 Origin、错误 Host/连接码拒绝、CORS 与私有网络预检、期限/任务绑定、并发排他、结果无缓存、仅内存读取、取消和丢失心跳后的迟到结果丢弃；自动发现、ASAR 边界及浏览器响应捕获原有回归保持通过。
- 真实 loopback 服务与生产前端联动，登录及官方身份接口使用 fixture：中英文、本地 HTTP 与 HTTPS 面板 origin、配对一次、首次自动预览、确认才保存、第二次登录复用连接、取消关闭，无下载/上传动作。HTTPS fixture 保留浏览器安全 origin 和生产 CSP，测试显式授予本地网络权限；不代表所有用户浏览器自动授予此权限。
- 保留的手动文件流程、TeleAgent 导入、实际 Chromium CDP、独立浏览器进程清理、账号创建、ChatGPT/Claude 入口回归通过。
- Docker 前端构建显式复制嵌入的单文件组件；Docker 上下文排除任务与结果文件。CSP 只新增固定 loopback 目标，未放开任意连接。

## 范围限制

真实 TeleAgent 验证码登录、逐模型调用和自然过期仍未执行。官方客户端元数据自动发现已在本机 3.0.0-rc.4 只读验证。Windows/macOS 真实桌面启动与 Windows 登录自启动尚待对应环境验收；Linux 自动启动项生成受测试覆盖，组件实际协议与浏览器生命周期已验证。

状态 schema 仍为 10。本批源码与升级包的验证不等于已更新系统服务，服务升级需使用受管升级工具保留账号、账本和升级前备份。使用说明见 [TeleAgent 接入](../TELEAGENT.md)。
