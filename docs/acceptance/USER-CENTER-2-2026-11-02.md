# 用户中心第二批验收（2026-11-02）

已实现并部署本地 `http://127.0.0.1:10088`，版本 `0.3.0-user-center-2`、schema 10。设计见 [ADR 0013](../adr/0013-consumer-entitlements-identity.md)，操作见 [用户指南](../USERS.md)。本地基线为 `136ccc8` / `baseline/user-center-1-20261102`。结果数据见 [JSON](USER-CENTER-2-2026-11-02.json)。未更新远程服务器、GitHub 或 Release。

## 实现范围

1. 额度：管理员十进制发放/扣减、操作原因、revision 防重复；整数计量、请求前估算预留、真实用量结算、取消释放、缺用量暂停；用户查看余额与流水。
2. 兑换：余额、并发、套餐码，生成后仅显示一次，持久化只存摘要；到期/停用/单次使用，核销与发放同事务；管理员与用户各自查看兑换记录。
3. 套餐：分组、天数、并发、请求/Token/USD 额度，UTC 日/周/月/总量周期；分配、同套餐续期、到期拒绝、停用/恢复、显式移除。模板与已有订阅快照分离。
4. 身份：SMTP TLS/STARTTLS、邮箱验证、忘记密码；GitHub/LinuxDO OAuth 显式绑定登录，PKCE、浏览器关联、单次 state、稳定 subject 唯一关联；配置读取不返回密码或 Secret。未接自动注册或按邮箱自动合并。

没有支付、在线充值渠道、订单、退款或邀请返利。CodeArts/WorkBuddy/Trae 适配器实现没有修改。

## 限制

- 生产 SMTP 和 OAuth 应用尚未配置，邮件验证、密码找回和第三方登录功能保持未启用。代码及模拟传输通过，真实邮件投递和第三方授权尚未验收。
- 钱包为参考 USD 的内部软额度。估算可能小于真实输出/多模态消耗；有效结果不截断，超额形成负余额并停止后续调用。
- 原用户/密钥及套餐 Token/USD 软预算保留单在途语义，余额预留支持并发。搜索缺计量回执，不能绕过额度限制。
- 流水展示保留全站最近 10000 条，累积余额独立保留；兑换码最多 10000 个，不清除已核销记录。
- 单进程 JSON/同步 journal；不支持多进程共写。schema 10 无向后导出，不得手改版本号或恢复旧凭据。
