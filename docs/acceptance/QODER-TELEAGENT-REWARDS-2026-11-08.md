# Qoder / TeleAgent 积分领取验收

## 交付范围

- Qoder 新增 DailyRewards 适配，CN/global 分区访问当前 campaigns；只提交当前窗口内、上游明确可领的 Credits 活动，按同一活动 ID 复查确认。
- 活动 ID 和金额从上游取得，重复条目去重，不使用旧 daily-check-in 接口；只读请求和提交均禁用缓存，提交不自动重放，错误不写入推理账号健康。
- TeleAgent 保留现有凭据分流、每日动作及提交后复查，补齐布尔值、数字 0/1、字符串形式状态字段的兼容；未识别状态不触发领取。
- 复用账号行按钮、批量领取、现有自动领取配置、按账号锁、结果持久化与额度缓存失效。没有新增数据库、后台服务、活动 ID 存储或推理路径查询。
- Qoder 去重日期按 UTC+8 10:00 切换；TeleAgent 保持现有 UTC+8 日周期。

## 操作方式

更新并启动新版服务后，在账号池选择 Qoder / TeleAgent 的「每日签到」；活动福利区选择对应账号并刷新，可先查询可领状态。顶部批量领取和「配置 → 活动福利自动领取」复用同一逻辑，自动领取不会因升级而自行开启。

空活动列表为暂不可领；提交后无法确认则为待确认，沿用现有等待期。请用官方余额与活动记录核对真实到账，不能把 HTTP 成功或活动标示金额当作余额实增证明。
