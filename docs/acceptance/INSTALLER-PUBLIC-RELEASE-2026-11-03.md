## 修改

API 的 403/429、常见 5xx、连接错误或超时触发公开入口备用查询。只接受本仓库 HTTPS latest → 稳定格式 tag 的跳转，公开下载 SHA256SUMS，再按原有限制下载与校验所需附件。公开请求不携带 Token，不改可信主机范围，不增加第三方镜像。

指定旧版本时不自动改装最新版；公开通道不能核实旧版本的 stable 标记，所以失败关闭。401、404、无效 API 元数据、草稿/预发布及摘要校验错误不触发放宽检查。check 模式仅确认公开校验清单含所需附件，安装才确认实际字节和状态。
