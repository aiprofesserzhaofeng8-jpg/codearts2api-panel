# TeleAgent 接入验收（2026-11-04）

本文件记录 v0.3.12 的初始接入范围。后续浏览器登录见 [登录助手验收](TELEAGENT-BROWSER-LOGIN-2026-11-04.md)。

## 范围

中国电信 TeleAI 的 TeleAgent，平台 ID `teleagent`、地区 `cn`。原生网关适配接入同一个账号池、分组映射、公共提示词/平台覆盖、租约、用量和预算入口。没有桌面代理运行时或独立选号/刷新循环。

当前添加方式为完整凭据导入。保存前通过上游 user_info 核对稳定身份；账号与网关密钥、设备信息分别处理。JWT 只用于补齐身份/有效期元数据，最终身份以服务端校验为准。没有可确认的续期协议，账号不标成可续期或长期密钥。

目录提供固定来源的五个产品档位，明确标注预置、上下文/输出上限未知，不将未知型号权限宣传为已经验证。积分分别支持账号业务 userCenter 与显式提供凭据时的独立门户；只有余额时不制造总额/已用量，0 与缺失不同。

## 验证结果

全部使用临时隔离状态与本机模拟上游，无真实账号凭据与付费请求。

- Node 标准库独立生成的固定签名向量与 Go 实现一致，验证中文请求字节、完整路径、账号令牌与安装绑定。
- 凭据校验：账号不一致、缺设备/安装/版本、无网关密钥、虚假续期、地区冲突、非法 Cookie、真实 JWT 到期上限、大整数账号 ID。
- 协议：工具与大整数参数、system/developer、SSE 完成与 usage、错误帧、截断、上下文取消、错误体脱敏。
- 身份/目录/积分仅执行只读 GET，重定向不会把凭据发到其他主机；独立积分门户凭据不发送到推理接口。未知余额不补零。
- server 集成：Chat Completions / Responses / Messages × 流式/非流式 × 文本/工具，共 12 个组合通过；分组统一名、原始型号白名单拦截、实际型号、Token/缓存计量与租约归零通过。
- 管理接口：普通 API Key 不能导入账号；导入需上游身份一致；管理员 state/额度响应不暴露令牌、网关密钥或设备信息。
- 持久化：新增平台设置默认兼容，提示词快照不共享可变指针，保存/重开与公共继承通过，schema 保持 10。
- `make check` 通过：Go 全包测试、vet、45 项前端测试、生成接口/架构/HTML/CSP 与部署工具检查。最后 UI 隐藏规则和密钥空后缀校验调整后，前端构建/完整 21 场景浏览器验收与平台 race 分别重跑通过。
- TeleAgent/storage/server 针对性 race 通过；完整 21 项浏览器验收包含中英文、390px、导入失败、敏感输入清空、平台/用量筛选、提示词继承，以及切回其他平台后恢复浏览器授权入口。
