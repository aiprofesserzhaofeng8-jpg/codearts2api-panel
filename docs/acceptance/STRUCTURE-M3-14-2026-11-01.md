# 全局设置与模型策略管理分离验收（M3 第十四批）

日期：2026-11-01。基线 `0ad241c`，版本 `0.3.0-structure-m3.14`。M3 尚未整体完成。

## 改动与边界

`config.Management` 接管全局设置补丁校验、三平台局部更新、密码变更规则、强制型号与分组映射冲突检查，以及模型策略的目录/别名、备用型号和平台校验。app 借用同一模型目录及当前别名，不建立另一份目录、配置缓存或锁。HTTP 保留管理员守卫、参数大小、JSON 解析、脱敏、状态码和身份头/限流热生效。

`Settings`、`ProviderSettings`、`PoolSettings`、`ModelPolicy` 的规范定义和七个纯规则/默认构造函数迁入 config；Store 保留兼容类型别名和默认构造入口，`DefaultSettings` 的原生默认值投影不变。AST 核对四种类型的字段、顺序及 JSON 标签一致，七个迁移函数体一致，Store 的 111 个函数体和其余 269 个 server 函数体未变。平台原生协议、页面、gateway、protocol、requestpolicy、accounts、access 和 registry 逐字节不变；准入、调度、权限、预算和账本仍走原入口。

本批保留两种历史保存语义：全局设置落盘失败只记日志，已发布的内存设置及身份头/限流继续生效；模型策略严格保存失败回滚。密码哈希和旧会话失效仍由原 Store 执行。三平台局部更新不覆盖其他平台或省略字段；摘要备用型号仍须同平台、同地区且不是自身，强制型号约束和仅 CodeArts 支持摘要保护的限制不变。不增加普通推理路径调用。
