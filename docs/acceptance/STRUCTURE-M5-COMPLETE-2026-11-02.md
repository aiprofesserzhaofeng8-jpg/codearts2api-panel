# M5 完成验收

日期：2026-11-02。状态：**M5 全部完成**。基线 `24fcff7`（M4），版本 `0.3.0-structure-m5`，定版标签 `milestone/structure-m5-complete-20261102`。详细指标见 [结构化记录](STRUCTURE-M5-COMPLETE-2026-11-02.json)，取舍见 [ADR 0009](../adr/0009-runtime-storage-ownership.md)。没有扩展 M6/M7 产品规则。

## 实现与边界

| 完成项 | 唯一归属及行为 |
| --- | --- |
| 准入协调 | gateway.Admission，经使用方定义的 AdmissionStore 统一预算和尝试准入；推理、搜索、成长付费动作保留各自原检查顺序 |
| 纯选择算法 | scheduler.Select/Legacy/MaxInFlight，storage 在原锁内借用当前候选；不复制权限或建立新缓存 |
| 业务存储接口 | storage 实现 accounts/access/config/catalog/gateway/jobs/usage 的窄接口；状态、锁、租约、预算、凭据 CAS 和账本只有一份 |
| 费用与预算规则 | usage 定义 DTO、费用计算、查询和分析；access 定义预算和密码规则；累加及持久化仍归 storage |
| 兼容编码 | files、compatibility、account_codec 分开；旧 store 只有别名/委托，架构检查禁止生产依赖它 |
| 凭据边界 | NativeCredential 为旧 CodeArts 不透明不可变代际；schema 6 的 session 键、指针 CAS 和外部平台原始 JSON 保持兼容 |
| 发布与故障恢复 | 验证实时权限、保存失败回滚、旧计划失效、删除后幂等释放、轮转 token 保存失败及强杀后的结算恢复 |

与初始设计相比，gateway 负责协调，storage 继续唯一持有运行状态和锁，没有再建立一套准入快照。原子性来自同一临界区，避免拆锁、复制候选和双份计数。14 个关键事务方法经包名/凭据字段名归一化后，AST 函数体与 M4 一致；全项目共有 1006 个原有函数通过同样比较。没有增加上游网络、重试预算、普通响应缓冲、凭据编解码或逐块写盘。

## 性能

同机、Go 1.27.3、GOMAXPROCS=2、CPU 0/2、临时 RAM 文件系统，前后版本交替运行。RAM 用于控制测试夹具磁盘波动，生产 fsync 和账本保证未改变。

21 项首轮基准中，20 项在 ±5% 内。短摘要截断重试一项初测 +6.45%，增加到 7 轮、每轮 2000 次后为 **+1.57%**，未确认是稳定退化；原始结果和复核结果均保留。另测 3 种策略 × 1/13/128 账号，共 9 组关闭黏性的真实选择：最大变慢 +1.43%，分配次数不变。

9 类并发场景 × 前后版本 × 5 轮，共 90 条记录：

| 指标 | 新版相对旧版的中位数变化范围 |
| --- | --- |
| 完整响应 p95 | -0.90% 至 +1.69% |
| 客户端首个有效输出 p95 | -1.81% 至 +1.72% |
| 吞吐（请求/秒） | -1.37% 至 +0.90% |

全部有效结果、预期上游调用次数、峰值并发及租约归零检查通过；未见超过 5% 的稳定退化。此结论仅适用于受控夹具，不能保证真实上游时延或任意规模负载。

## 限制

严格管理事务仍可能在原状态锁内等待磁盘；部分历史设置/启停操作保存失败仍仅记日志。日志和历史的外层切片是副本，嵌套值继续只读使用，不宣称全量深复制或无锁发布。单进程状态文件不能被多个进程共同写入；真实断电、硬盘固件和 Windows 目录同步未验收。

M5 无剩余实现项。映射预设、分组默认、可见/可调用开关和公共提示词继承属于 M6；数据库、多用户或多实例属于 M7，需单独实施和验收。
