# 管理增强

本项目仍是单进程、单管理员的网关。管理分层参考 Sub2API。

| 功能 | 面板入口 | 行为 |
| --- | --- | --- |
| 管理员登录 | 打开面板；右上角退出 | 8 小时会话；退出、改密、进程重启撤销 |
| 凭据续期协调 | 自动生效 | 同账号串行续期，提交时检查凭据版本，旧续期不覆盖新登录或复活已删除账号 |
| 账号模型健康 | 账号池 → 模型健康 | 模型限流/不可用仅冷却对应账号的该模型；凭据失效仍冷却整个账号 |
| 管理操作审计 | 侧栏管理审计 | 登录、退出、配置更改、显密/导出等写操作；分页、最近 5000 条 |
| 摘要备用模型 | 模型 → 兼容策略 → 编辑 | 主模型摘要截断后最多一次备用生成；默认关闭 |
| API Key 预算 | API 密钥 → 预算 | 请求数、输入加输出 Token、USD 参考费用；0 不限，可重置已用值 |
| 账号独立并发 | 账号池 → 账号右侧「并发设置」 | 码道、WorkBuddy、Trae 均可独立设置 1–32；也可使用全局默认值 |
| 账号分组 | 侧栏 → 账号分组 | 选择账号及模型白名单，将密钥绑定分组；模型目录与请求调度使用同一访问范围 |

## 账号分组

在侧栏「账号分组」创建分组，勾选可用账号。需要缩小模型范围时，启用「仅允许选中的模型」并多选模型，然后保存。进入「API 密钥」，点击「创建密钥」在弹窗中填写备注、选择分组并确认创建；已有密钥点击右侧「分组」修改绑定。

一个账号可属于多个组，每个密钥只能绑定一个组。不分组的密钥保持原有行为，可使用全部账号。分组为空时没有可调用模型；启用白名单但未选择模型时禁止所有模型。仍有密钥绑定的分组不能删除，需先修改密钥分组（包含停用密钥）。保存失败会回滚配置。

绑定分组的 `/v1/models` 只展示该组已启用账号对应平台、地区的模型，并应用白名单。同一模型 ID 只出现一次；跨平台同名模型保留 `workbuddy/cn/...`、`trae/cn/...` 等来源前缀，避免混用计费渠道。「模型」页面将刷新、批量测活与筛选区分开，支持按组预览及模型名称 / ID 搜索，数量随筛选更新。「批量测活」仅提交当前列表中的真实模型，空列表不发起测活；管理端的测活账号仍由管理员接口选择。

Chat Completions、Responses 和 Messages 均限制到组内账号；粘性会话、满载换号、失败重试不会借用组外账号。模型别名、强制模型及摘要备用模型按实际模型校验白名单。组内账号的并发、暂停、冷却和密钥预算仍分别生效。配置变更影响后续准入，不中断已发起的上游请求。

管理接口：`GET/POST /admin/api/groups`；保存请求字段为 `id`（新建省略）、`name`、`account_ids`、`allowlist_enabled`、`model_ids`。`DELETE /admin/api/groups?id=GROUP_ID` 删除未绑定分组。`POST /admin/api/keys/group` 接受 `{"ref":"KEY_REF","group_id":"GROUP_ID"}`，空 `group_id` 解除绑定；`POST /admin/api/keys` 创建时支持 `group_id`。状态文件 schema v4 保留分组与绑定；降级需同时恢复升级前备份和旧程序。

## 账号并发设置

账号右侧「并发设置」默认勾选「使用全局默认值」，沿用配置页「账号池调度 → 单账号默认并发上限」。取消勾选后可输入 1–32 的整数。独立值覆盖默认值，因此可以比默认值高或低；API Key 的并发和预算限制仍另外生效。

保存立即影响后续请求的账号准入，流式请求直到完成或断开才释放名额。降低上限不会中止在途请求；若当前在途数量已达到新上限，该账号暂停接收新请求，直到名额释放。粘性会话也受独立上限约束，满载时会尝试池内其他可用账号。

独立值保存在账号的 `max_in_flight` 字段，0 或旧状态文件中缺失该字段表示继承。重新登录或替换账号凭据保留独立设置。保存失败会回滚，不能出现界面提示失败但调度已改的情况。

管理接口：`POST /admin/api/accounts`，请求 `{"action":"concurrency","id":"ACCOUNT_ID","max_in_flight":3}`；恢复继承时传 0。管理状态中的账号顶层 `max_in_flight` 是独立配置，`pool.max_in_flight` 是当前实际生效值。

## 登录与恢复

默认本机和远程都要求登录。首次密码在 `data/state.json.access.json` 的 `admin_password` 字段；该文件是初始值记录，之后不会跟随改密。旧部署原先没有密码时生成 `data/state.json.admin-recovery.json`。忘记密码可通过 `CODEARTS_ADMIN_PASSWORD='新密码' ./start.sh` 重设；运行服务需在其启动环境中配置后重启。

状态文件当前为 schema v4，旧版本程序会拒绝读取，避免丢弃分组、预算等配置。降级需同时恢复升级前的状态备份和旧程序。

状态文件中的管理密码自动迁移为 PBKDF2-SHA256、600000 次迭代、16 字节随机盐。浏览器清理旧版保存的密码，改用 HttpOnly、SameSite=Strict Cookie；直连 HTTPS 时 Cookie 另带 Secure。远程部署应在 HTTPS 入口终止 TLS，或使用 SSH 隧道。不要通过公网明文 HTTP 登录。反代终止 TLS 时应用不会无条件信任客户端的 X-Forwarded-Proto；应由可信反代统一设置 Secure Cookie。

会话只存服务进程内，保存的是随机令牌摘要。所有当前会话在改密后失效；没有多用户角色、2FA 或跨实例会话。管理脚本仍兼容 `X-Admin-Password` / Bearer。默认模式不能在设置里清空密码，防止把自己锁在无密码状态。

若明确需要旧行为，可显式设置 `CODEARTS_LOCAL_AUTO_UNLOCK=true`。这是兼容选项，会重新信任可直连本机服务的进程；默认关闭。

初始访问凭据文件、可复制 API key、上游 STS/refresh token 和历史备份仍可从文件读取，使用目录 0700 / 文件 0600 保护。密码哈希不等于全部凭据加密。

## 健康状态与续期

正常推理的 429/并发限制按调度设置冷却对应模型；5xx 短冷却至多 5 秒。明确的模型不存在/暂不可用错误会尝试其他账号。普通参数错误、摘要截断、预算拒绝不计入账号凭据故障。模型冷却结束后允许恢复，成功请求清除该模型失败计数。「解除冷却 / 清错」同时重置账号和模型健康状态。

刷新凭据时先读取 Store 中最新快照，再提交有版本检查的会话替换；手工更新/浏览器重登如果发生在续期网络请求期间，旧续期提交会失败而不会覆盖它。已轮转凭据写盘失败时保留内存中的最新值，由后续保存重试；应及时检查服务日志和磁盘。协调仅适用于单个进程，不支持多个实例共享状态文件。

## 摘要备用模型

仅对已识别的摘要请求生效，普通对话和工具调用不切换模型。须开启摘要保护、截断重试，并显式选其他目录模型。主模型得到 `finish_reason=length` 才进入第二次生成；两次共用账号和总超时，不无限换号。备用模型也必须能容纳原历史，未配置策略时不会复制主模型的关闭思考参数。强制模型设置会限制备用模型调用。

所有片段先缓冲，完整成功才向客户端输出。日志 `attempt_details` 保留每次实际模型、usage、费用单价快照。总费用按每次实际模型相加；未配置价格/漏报 usage 的部分不伪造。最终摘要响应的 usage 是成功生成那次，管理用量和密钥预算累计全部已报告消耗。

## 预算语义

预算从本功能启用后的调用累计，或从手动重置时重新开始；不把旧的「请求数」（含模型列表等查询）混作推理预算。推理重试按一个逻辑请求计次数，Token 与费用累计所有已报告尝试。重置统计或清空日志不重置密钥预算，重置预算也不删除历史用量。

- 请求次数在调用前原子预留，避免并发突破次数限制；参数错误未发起尝试时释放预留。
- Token / USD 在响应结束后结算。启用其中一项时，一个密钥最多一个在途推理，单次请求仍可能超过剩余预算；它们不是预先精确计费的硬上限。
- 如果首轮摘要已耗尽 Token / USD 预算，不再发起第二轮生成。
- 预算用尽返回 HTTP 402，OpenAI 错误类型为 `budget_exceeded`；Messages 为 `permission_error`。模型列表和能力查询仍可使用。
- 上游漏报 usage 时标记未知；有 Token / USD 限额的密钥暂停调用，需人工核查并重置。已有未定价消耗时，USD 限额同样要求核查后重置。
- USD 限额要求实际使用的模型已配置价格，包含备用模型。所有费用均是 USD API 参考估价，不能换算为确定的华为积分；不支持华为每日积分硬限额。
- 密钥有在途请求时禁止修改/重置预算；完成后重试。

状态每 30 秒及正常退出时原子保存。异常断电可能丢失最后一周期用量；这里没有事务数据库、支付账本或跨实例预算承诺。

## 管理接口

- `POST /admin/auth/login`，JSON `{ "password": "..." }`；`POST /admin/auth/logout`；`GET /admin/auth/session`。
- `GET /admin/api/audit?page=1&page_size=50`，单页最大 200。
- `POST /admin/api/keys/budget`：`{ "ref": "key_...", "budget": { "max_requests": 100, "max_tokens": 1000000, "max_usd": 1 }, "reset": false }`。ref 来自鉴权后的密钥列表，不需在 URL 中传完整 key。
- `POST /admin/api/model-policies` 的 policy 新增 `summary_fallback_model`，空字符串关闭。
- `GET /admin/api/state` 的账号包含 `model_health`，密钥包含 `budget` / `budget_usage`。

审计仅记录时间、认证方式、固定接口路径、白名单操作名、直连来源 IP、状态码；不保存请求正文、查询参数、密码、会话令牌、授权码或密钥值。失败登录也记录。最近记录与用量一样依赖定期落盘，不提供不可篡改日志保证。

## 验证

`go test -race ./...` 覆盖会话失效、跨站拒绝、密码持久化、续期版本冲突、模型隔离和恢复、预算并发预留、三种协议预算、摘要预算中止、备用模型与分模型计价。Playwright 在独立 10088 测试实例验证正式登录、预算弹窗、审计及移动布局；模拟接口回归账号添加/删除、分页、价格表、模型策略。
