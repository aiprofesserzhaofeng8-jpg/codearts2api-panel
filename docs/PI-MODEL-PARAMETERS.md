# Pi 模型参数配置表

配置快照日期：2026-11-24。范围：本机 Pi 的 `codearts-local`，共 140 个模型条目。不同名称可能指向同一个底层模型，条目数不代表独立模型数。

## 配置规则

| 参数 | 当前设置 |
| --- | --- |
| 最低上下文 | 131,072 Token；已有更大窗口保留 |
| 最大输出 | 默认 65,536；已对齐的 GLM、MiMo 入口为 131,072；MiniMax-M3.1-Flash 为 524,288 |
| 压缩预留 | 138 个条目为 16,384；TeleAgent 旗舰、Nano 的统一名称入口为 36,864 |
| 近期历史 | 保留各模型原配置；未设置时按本机 Pi 默认 20,000 计算 |
| 压缩阈值 | 上下文窗口 − 压缩预留；上下文超过阈值时触发检查 |

项目规则保存在 [model-settings.json](../scripts/pi/model-settings.json)，由 [connect-client.py](../scripts/connect-client.py) 应用。本表读取 `~/.pi/agent/models.json` 和 `~/.pi/agent/settings.json` 生成，仅记录模型参数。

表中数值是当前客户端配置。最大输出及最低窗口由管理员指定，不表示所有上游均已验证支持。Pi 的自动压缩是否启用及项目级设置可能影响实际触发；新参数需客户端重新加载后使用。

`glm-5.3` 按 [Z.ai 官方文档](https://docs.z.ai/guides/llm/glm-5.3) 的 1M 上下文、128K 最大输出配置为 1,000,000／131,072 Token（2026-11-24）。WorkBuddy 同名入口已通过 983,361 Token 长输入召回测试，详见[本批实测记录](acceptance/PI-CONTEXT-ALIGNMENT-2026-11-24.md)。

## 参数来源与同步行为

- **项目覆盖**：精确名称存在于项目配置；同步时仍保留比覆盖值更大的已有窗口。
- **最低窗口**：没有精确覆盖，当前采用 131,072；其上游最大窗口尚不能由本表确定。
- **本机保留**：此前已经存在的大窗口；本表不将其追溯认定为官方规格。

同步时取已有窗口、网关窗口、项目最低窗口和精确覆盖值中的最大值。已有压缩预留与近期历史配置不覆盖，缺失时才从网关补充。新机器未必具有本表的全部保留值；复制单文件启动器时，也需带上同目录下的 `pi/model-settings.json` 才能应用项目偏好。

DeepSeek 无后缀 `deepseek-v4.1-flash` 曾使用旧的 65,536，设置最低窗口后升为 131,072，现已在项目中配置为 1,000,000。这是客户端工作配置；`deepseek-v4.1-flash-1017` 的公共规格记录不能独自证明所有无后缀渠道都支持相同上限。

TeleAgent 实测窗口依据见 [测试记录](acceptance/TELEAGENT-LIMITS-2026-11-23.md)。TeleAgent 条目的输出统一为后来指定的 65,536，与该记录中的实际完成输出长度不同。
