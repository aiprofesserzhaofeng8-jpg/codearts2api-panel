# 控制台：首次调用与请求排障

参考 Sub2API 2af3f1e 的密钥使用弹窗、用量筛选和错误详情。保留本项目的账号池、分组授权与统一模型；不改变网关路由、计费或凭据格式。

| 批次 | 工作 | 验收 |
| --- | --- | --- |
| 1 接入 | 空账号页直接打开已有添加向导；用量采用账号池平台目录并保留记录中出现的历史平台；管理员与普通用户的密钥行提供「使用」，生成 cURL、Codex、Claude Code 配置 | Kimi 可筛，Gemini 不漏；配置地址不重复 /v1，不自动发送请求，不在示例显示密钥。目录展示权限和调用权限分别验证，无授权型号时不生成猜测值 |
| 2 排障 | 管理员用量行可打开请求详情，复制请求 ID；模型页以可复制的公开名和来源为入口，提供请求型号与实际型号不一致的历史筛选 | 无需悬停即可查出错误、上游和型号；仅显示实际记录，未选中上游的请求不伪造来源。映射筛选在分页前执行 |
| 3 阅读密度 | 手机账号默认保留名称、平台、状态和异常，按需展开；首次无请求和筛选无结果显示不同操作 | 360px 可用；初始空数据不占四块空图，筛选无结果可恢复，加载失败不显示为零用量 |

每批先用隔离数据验证中文版、英文版及关键操作，再交付。权限投影沿用服务端规则，不在前端重建准入；只改管理视图，不向普通用户暴露后台账号。部署、发布另行执行。

## 首次交付

已完成账号空态、用量平台筛选、记录中出现的历史上游选项及管理员请求详情。
浏览器用例 `console-first-call-smoke` 验证空态打开向导、Kimi 查询参数、历史平台、失败请求的型号和 ID、关闭弹窗后焦点返回；覆盖中文桌面和英文 360px。
## 接入与排障交付

管理员和普通用户的密钥行提供「使用」。服务端校验引用及归属，用目录可见集合与实际请求解析结果筛选公开名；不增加请求计数。cURL、Codex、Claude Code 示例只引用环境变量。

管理员模型页先显示公开模型，可复制名称、展开来源；启用数不等于在线数。用量筛选「请求与记录型号不同」按历史字段精确比较，缺任一字段不匹配；统计和分页共用筛选后的集合。

## 阅读密度交付

手机账号按 ID 保留本次会话的展开状态；默认显示名称、平台、状态与错误，展开才显示额度、凭据、并发、奖励、最近使用及操作。桌面沿用列偏好。

管理员用量按成功响应的保留记录数区分尚无记录与筛选无结果：前者进入 API 密钥，后者清除时间和字段筛选。错误单独显示并保留查询条件，重试成功后恢复结果；错误不渲染零计数。空结果不显示四张空图。
