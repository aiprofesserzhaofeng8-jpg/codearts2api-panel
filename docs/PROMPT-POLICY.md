# 公共与平台提示词

「配置」页顶部设置公共提示词，再在 CodeArts、WorkBuddy、Trae 的模式、正文、拦截恢复和清洗四项旁分别勾选「继承公共值」。未勾选的项目继续使用平台独立值。旧配置升级后全部保持独立，不会自动改写客户端请求。

- 自定义模式替换 system/developer，正文留空使用原内置工程助手提示词。
- 透传模式保留客户端提示词；拦截恢复开启时，只有明确内容策略拦截且尚未观察输出才按原规则重试一次。
- 关闭清洗是有效配置；继承与关闭不同。清洗边界仍限 system/developer，不改用户正文、工具参数、工具返回或推理内容。
- 摘要保留现有豁免，切换平台重新基于原始输入准备。搜索地区、开关、后端和 URL 继续按平台独立设置。

管理 API 示例：

```json
{
  "common_prompt": {
    "prompt_mode": "custom",
    "prompt_text": "按用户要求回答，准确说明不确定之处。",
    "prompt_fallback": true,
    "sanitize": true
  },
  "workbuddy": {
    "prompt_overrides": {"sanitize": false, "prompt_text": ""}
  },
  "trae": {"prompt_overrides": {}}
}
```

Trae 四项都继承；WorkBuddy 继承模式和恢复开关，清洗明确关闭、正文明确为空。`prompt_overrides: null` 恢复旧的平台独立配置；对象中的 null/缺省字段继承公共值。

保存前所有平台的有效配置都会校验。平台字段仍保存在原配置中，继承时界面展示有效公共值。修改只影响后续准备的请求，不回写历史日志。全局设置保留既有内存发布与保存失败日志语义；磁盘故障时应检查运行日志并处理，不能仅凭界面成功提示认定已持久化。
