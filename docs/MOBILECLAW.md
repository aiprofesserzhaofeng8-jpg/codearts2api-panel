# MobileClaw（中国移动云）

支持把 MobileClaw **个人免费 Token 账号**加入账号池，提供身份校验、套餐过滤后的模型目录、余额查询和 OpenAI 流式转发。不是将 MobileClaw 配成本网关客户端。

## 扫码或链接授权

1. 面板「添加账号 → MobileClaw → 浏览器授权 → 生成登录链接」。
2. 使用手机扫描二维码，或复制登录链接到手机打开。地址为中国移动认证域名 `www.cmpassport.com`。按官方要求关闭 Wi-Fi，使用蜂窝网络确认。
3. 面板自动检查；出现账号预览后核对身份，点击确认保存。无需手动粘贴回调地址。
4. 有效期由上游提供（实测 120 秒）；过期重新生成。取消/关闭会停止检查，不自动保存账号。

如果尚未绑定移动云账号，或返回多个未选定的账号，请先在官方客户端完成绑定/选择，再走下方凭据导入。此版本不自动替用户选择云账号，不实现 SMS 登录。新扫码账号支持按需续期。

## 凭据导入（保留的替代方式）

1. 在官方 MobileClaw 客户端登录并绑定移动云账号，选择个人工作空间。
2. 面板「添加账号 → MobileClaw → 导入」，下载导出助手。
3. 在已登录客户端的电脑上运行 `node mobileclaw-export.mjs`（需要 Node.js）。Linux 默认识别 `/opt/MobileClaw` 和当前用户配置。
4. 将生成的 `mobileclaw-credentials.json` 内容粘贴到面板，点击「校验并导入」。文件包含访问凭据，请勿公开。
5. 刷新模型目录，使用 `mobileclaw/cn/<真实型号>`；统一模型预设仍由管理员显式预览和应用，不静默修改现有映射。

其他安装位置可传 `--config 配置路径 --app-asar 安装目录/resources/app.asar --output 新文件路径`。不覆盖已有文件，不修改官方客户端配置。Windows/macOS 路径需指定，尚未实机验证。

## 当前边界

- 不支持付费/企业套餐和套餐切换，不把全部官方目录型号都列为账号可用。
- 支持二维码/链接授权；本次版本新扫码保存的账号保留独立设备与刷新令牌，启用全局自动续期后按需刷新。旧扫码账号需再扫码一次，桌面导入仍需重新导入，不轮转官方客户端共享令牌。尚无短信登录；覆盖已有账号需要显式确认。
- 显示免费 Token 余额，不推断不明确的总额与已用量；没有自动领取福利。
- 原生模型名和每个来源支持的功能分别处理，不因名称相同就宣称支持图片或工具。
- 接入没有文件存储服务或新的后台常驻进程。

协议证据见 [UPSTREAM.md](../backend/internal/upstream/mobileclaw/UPSTREAM.md)。

2026-11-14 用户反馈：手机扫码登录已成功，但需使用对应手机号的蜂窝网络。续期使用官方 `/auth/refresh` 协议，模拟测试已覆盖成功及失败分支；当前尚未完成真实令牌轮转验证。

## 供应商授权修复（2026-11-14）

扫码获得云账号令牌后，如果令牌尚无供应商绑定，面板查询可用 FREE 套餐，并在供应商唯一时携带 userId、aiProvider 和本次扫码的设备信息调用官方刷新接口。返回令牌的账号与供应商必须匹配，才能进入确认保存。多个免费供应商时不任意选择，提示在官方客户端选择后导入。

续期保留已绑定供应商并核验返回值。供应商查询仅在登录完成阶段执行，不增加每次对话的网络查询。授权刷新结果不明确时要求重新扫码，不自动重放可能已轮转的刷新请求。

此前已扫码但令牌缺少 aip 的账号，升级后需重新扫码并显式替换。不会就地编辑旧 Token 或把请求头当作供应商授权。修复后的扫码凭证真实生成及续期仍待验证；官方客户端凭证直接请求 glm-5.3 已验证成功，不能替代面板扫码验收。
