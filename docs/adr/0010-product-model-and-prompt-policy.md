# ADR 0010：分组模型规则与公共提示词

状态：采用，M6。日期：2026-11-02。

## 模型

沿用 `catalog.Routing → gateway.Admission → storage.Store`。预设为 catalog 内版本化 JSON，只在编辑器显式应用，不自动更新已存来源，不根据模糊名称认定不同型号等价。管理接口返回每个来源在当前目录中的可用性；编辑器进一步按账号范围和白名单过滤。目录缺失的旧来源保留并提示，不自动换成其他型号。

`AccountGroup.default_model` 只处理空 model。已写名称仍按该名称解析，未知名称 404；分组没有来源时保持不可用错误。未配置该字段维持旧规则，包括 Responses 原有的必填检查。无映射分组的全局强制模型仍优先，映射与强制模型仍互斥。

`client_default_model` 独立保存，必须可见且允许调用。`/v1/models.default_model` 和未指定型号的 `/v1/client-profile` 提供该偏好；Pi、Codex、Claude 启动器不再硬编码覆盖它，显式 `--model` 优先。客户端是否采用这个扩展由客户端自身决定。

`model_rules` 引用公开名或原始目录 ID，`visible` 与 `callable` 为独立的可空布尔值。缺省公开名展示、原始型号在有映射时隐藏；调用缺省允许但仍受原账号、白名单、能力、预算约束。原始来源禁用同时影响引用它的映射；公开名禁用不自动禁用其物理来源。显示物理 CodeArts 型号时使用 `codearts/` 完整 ID，避免与公开名冲突。

原子准入在原锁内复核最新公开名调用开关、来源规则、成员和白名单，再选择账号与实际型号、占用名额。列表快照不是权限凭据，隐藏不是禁止，陈旧计划不能绕过刚生效的限制。新快照对规则和提示词指针进行深拷贝；无配置时无额外规则分配，无新网络查询、锁域或重试层。

## 提示词

公共配置只包含 `prompt_mode`、`prompt_text`、`prompt_fallback`、`sanitize`。搜索配置独立留在平台中。`prompt_overrides: null` 保留原平台策略，`{}` 继承全部；对象内未设置/null 字段继承，false 与空字符串是显式值。编辑器逐字段显示继承状态。

旧状态迁移不替平台勾选继承，不更改实际提示词。只在选定平台后求有效值，仍从原请求准备每次尝试。custom 的 fallback 开关休眠，只有 passthrough 遇明确拦截且未观察输出时才按原规则最多恢复一次。摘要继续豁免注入；不递归清洗用户或工具数据，不增加按账号/模型/分组的提示词层。

## 数据与回退

schema 从 6 升至 7，防止旧程序静默忽略新的禁止调用规则。升级保留凭据、账本检查点、历史价格和原平台设置。旧版本直接读取会拒绝；不能用旧账号备份覆盖已轮转凭据。

需要回到 M5 时，停止写入进程，复制最新整个 data 目录；先在 M6 中清除分组默认、客户端偏好和模型规则，再使用 `tools/convert_state_v7_to_v6.py` 导出到新文件。它拒绝不能表达的模型规则，将公共继承展开为平台显式值，并复制用量账本 sidecar。输入文件不被覆盖，输出仍应先用 M5 隔离启动验证。迁移和回退都不允许多个进程共写。

分组保存仍为严格落盘事务，失败回滚。设置沿用先校验再发布、Save 失败记日志的既有语义；本次不宣称所有设置都具有磁盘提交原子性。多管理员并发编辑也没有新增版本冲突检测。这两个独立改进不混入 M6 的模型/提示词规则。
