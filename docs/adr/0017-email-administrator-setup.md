# ADR 0017：邮箱管理员与无 Token 首次安装

状态：已实施于当前源码，2026-11-03；尚未包含在 v0.3.7 发布包。

## 行为

首次访问空实例时，填写管理员邮箱、至少 12 字节密码和确认密码；不再读取或输入初始化 Token。邮箱仅作为登录标识，按格式验证并转为小写，不检查邮件收取能力，不标记为已验证，不提供邮箱服务或管理员邮件找回。

参考 Sub2API 的首次创建管理员邮箱与安装完成锁定流程，独立实现。管理员内部 ID 和角色不变，未设置 admin_email 的旧实例继续使用 admin，已有普通用户仍用用户名登录。普通用户由管理员创建，不开放注册。

## 边界和存储

- access 验证邮箱与密码，串行执行密码哈希和初始提交；storage 在同一事务中复核空实例、写入 settings.admin_email、密码哈希和默认 API 密钥，失败回滚。
- admin_email 为 schema 10 的可选配置字段；旧状态缺字段仍使用原 admin 登录。回退到不支持此字段的旧程序会恢复旧 admin 登录名，密码不变；建议向前升级。
- 临时安装 HTTP 实例与正式业务隔离，严格 JSON、同源校验、失败限流、并发单次提交；成功不自动签发登录会话。正式运行永远关闭初始化写入口。
- *.setup.json 只保存 pending 标记，部署备份工具可识别待安装实例；兼容并在完成后清理旧版遗留的凭证文件。*.installed、状态、账本和恢复文件继续阻止误删快照后的重新初始化。
- 管理员邮箱不提供在公开 setup/status 中查询；认证成功后的会话显示实际邮箱。

## 部署约束

取消服务器控制权凭证后，能访问空实例的人可以提交首次管理员设置。安装默认监听 127.0.0.1；公网部署必须先限制访问或通过 SSH 隧道完成初始化，再开放访问。此约束无法仅依靠安装完成锁或同源检查替代。

## 验证

覆盖邮箱格式、大小写、旧 admin 兼容、错误密码、会话撤销、并发提交、失败回滚、重启持久化、跨站拒绝、重复初始化拒绝，以及浏览器首次安装到管理员创建普通用户的完整流程。测试只使用隔离数据，不调用真实模型或修改现有部署。
