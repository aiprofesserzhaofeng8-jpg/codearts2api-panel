# ADR 0016：稳定的界面语言与浏览器偏好

状态：已实施，2026-11-03。

## 问题与参考

原界面没有应用级语言状态，固定中文文案也不能随浏览器语言完整切换。需要自动检测、手动选择及刷新后的持久化，并避免后台轮询或切页使中英文交替出现。

参考 Sub2API 的 [语言初始化](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/src/i18n/index.ts)、[LocaleSwitcher](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/src/components/common/LocaleSwitcher.vue) 和 [AppHeader](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/src/components/layout/AppHeader.vue)：统一语言状态、右上角国旗/语言代码菜单、选中标记、先保存再刷新。独立实现交互，保留本项目样式，没有复制第三方源码或引入新的国际化依赖。按本项目需求采用中文回退值，并增加“跟随系统”选项。

## 选择规则

1. 有效的手动 `zh` / `en` 偏好优先，存储键为 `codearts2api_locale`。
2. 否则按浏览器偏好顺序寻找 `zh` / `en`，支持地区、大小写和中文繁体语言标签；无支持语言则回退中文。
3. 自动检测只在页面加载时执行；不将检测结果保存为手动选择，不监听事件动态更改已挂载的语言。浏览器环境改变后，下次加载的自动模式自然使用新语言。
4. 手动切换先保存再刷新；跟随系统清除手动偏好。普通本地存储不可用时用当前标签页会话存储；保存失败或读回值不一致时显示错误，不刷新。

## 职责与边界

- `src/i18n/index.ts`：唯一检测入口、初始化 `html.lang`、界面词条查询、日期/数字 locale、偏好读写。初始化在 Vue 挂载前完成。
- `src/i18n/locales/en.json`：显式英文词条，中文原文作为键和回退值。只翻译受源码控制的界面文案，不扫描或替换任意 DOM 文本。
- `layouts/LocaleSwitcher.vue`：管理员/普通用户共用顶栏及登录/安装页的响应式菜单，支持选中标记、外部点击关闭、方向键、Escape 与焦点返回。
- `api/client.ts`：现有同源客户端维护在途写请求数量，菜单在写入期间禁用，完成或失败后恢复。原查询取消、认证和已提交写入语义不变；子组件不取得客户端生命周期。
- 遗留 `v-once` 控制器显式调用翻译函数，保持自己的 DOM 所有权。导航以稳定 ID 绑定，不以翻译后的标签作为逻辑选择器。页面级刷新使 Vue 与原生控制器同时采用新语言；不在轮询中重挂载页面。

偏好只属于当前浏览器，不加入服务端账号或状态 schema；管理员、普通用户、登录与退出共用。切换刷新会丢弃未保存草稿，与普通刷新一致。日期/数字格式跟随界面语言，时区不变。用户输入、模型 ID、账号名、平台响应和 API 参数不参与翻译；服务端错误及上游活动内容保留原文。

本批只修改前端界面，不调整认证权限、三个平台协议、调用模型、奖励流程或账本。
