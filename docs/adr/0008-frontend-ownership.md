# ADR 0008：前端组件与原生渲染的所有权

- 日期：2026-11-02。
- 状态：已实施，见 [M4 验收](../acceptance/STRUCTURE-M4-COMPLETE-2026-11-02.md)。

M4 使用 Vue 3 / TypeScript / Vite / pnpm 建立独立前端工程。为控制风险，现有安全文本渲染、图表和复杂授权流程按功能迁成原生 DOM 控制器，不在同一阶段重写为响应式表单。页面和平台专属模板使用预编译 SFC，静态子树由 `v-once` 固定，控制器独占节点，应用生命周期统一装配及清理。页签保留挂载以保存草稿。

全量遗留脚本改写为严格 TypeScript 或 v-for 表格会扩大行为差异，因此不作为本次前端工程化的完成条件。新基础设施、共享控件和生成的公开 DTO 使用 TypeScript；遗留控制器暂允许 JS，通过构建、组件测试、真实浏览器、DOM 约束和视觉对比验收。该取舍意味着不能宣称所有遗留函数都有静态类型保证。

后续新增交互优先建立独占 DOM 的响应式组件；接管旧节点时同时撤销旧控制器及事件，不允许通过去掉 `v-once` 形成双重控制。跨 feature 使用函数边界，状态对象保留在功能内部。对旧逻辑做类型补充应与新增功能一起按实际需求完成，不能为了文件后缀引入大面积 any 或 ts-nocheck。

生产产物复制到 `internal/webui/dist` 再 go:embed；目录缺失时不生成无页面版本。构建元信息随资源输出，严格 CSP、同源资源和不缓存本机会话的要求不变。Go 网关、存储与平台执行路径不参与此前端工程化。
