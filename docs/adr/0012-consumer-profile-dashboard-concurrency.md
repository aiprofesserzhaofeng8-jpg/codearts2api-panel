# ADR 0012：用户中心第一批——并发、资料与仪表盘

日期：2026-11-02。状态：已实施并验收，见 [用户中心第一批报告](../acceptance/USER-CENTER-1-2026-11-02.md)。

## 范围与参考

参考 Sub2API `4a4a83ee5ec86b19d3a2dd9b6471de5128963bec` 的用户/账号分离、独立用户并发、资料字段局部更新以及全量筛选结果统计。保留本项目单实例、一个用户一个分组、文件结算账本及三个独立平台适配器。未引入余额、支付订单、订阅、兑换、返利或第三方用户登录。

## 决定

- `access.User` 增加并发上限、昵称与小型内嵌头像；资料校验与 DTO 归 access。`storage` 继续唯一管理事务和持久化。资料更新仅补丁写入昵称/头像，并在原锁内检查用户启用状态及会话 revision；不能整行覆盖并发结算或管理员修改。资料保存不变更 revision。
- 用户并发复用 `BeginKeyBudget` 已有的 `user:<id>` 在途计数与幂等释放函数，不增第二把锁、权限缓存、重试或后台任务。所有密钥共享、整个逻辑请求持有一次，换号和重试不重复占用户槽位。达到上限立即返回 429，保留当前无排队语义；与 Sub2API 的等待模式有所不同。取消时沿用既有处理结束释放，不提前释放仍在执行的请求。
- 0 表示不限，已有用户保持 0；管理员页面创建默认 5。当前 Token/USD 软预算仍单用户最多一个在途，不借并发设置扩大可透支范围。保存更小并发上限不取消现有请求。
- 仪表盘直接使用已有 `/user/api/usage` 的完整筛选统计、模型分布和趋势，不另建用户报表存储或每请求统计任务。补充浏览器时区解析，过滤用户 ID 后才聚合和分页。保留已有明细保留范围、历史公开号码与敏感字段投影。
- 新 Vue 组件各自拥有资料及仪表盘节点，复用浅黄色明暗主题。头像只在显式上传时压缩及校验，推理请求不处理图片；服务端拒绝 SVG、外部 URL、不完整图片和超限尺寸。仅 `/user` 文档 CSP 开放 data 图片，脚本、样式和管理员 CSP 保持原限制。
- schema 9 防止旧版本静默丢弃用户并发权限。8→9 保留旧配置和所有权，不修改已有用户限额；不存在 9→8 自动降级，不能手工删字段或修改版本号。

## 验证要求

跨密钥同时准入、降低限额及幂等释放；三协议取消与用户/账号槽位回收；拒绝调用不执行上游或扣预算；资料局部更新、失效会话拒绝、保存失败回滚；跨用户统计隔离、全范围分页和浏览器时区；真实二进制的头像压缩/保存/重载、明暗主题和手机布局；迁移、原完整回归、race 和前后准入基准。

源实现：[并发服务](https://github.com/Wei-Shaw/sub2api/blob/4a4a83ee5ec86b19d3a2dd9b6471de5128963bec/backend/internal/service/concurrency_service.go)、[资料服务](https://github.com/Wei-Shaw/sub2api/blob/4a4a83ee5ec86b19d3a2dd9b6471de5128963bec/backend/internal/service/user_service.go)。本批不声称复现其支付、订阅或跨实例能力。
