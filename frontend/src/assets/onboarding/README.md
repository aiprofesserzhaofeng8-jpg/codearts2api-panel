# Account onboarding icons

Browser and import SVGs are original artwork under the repository license.
Blue browser/check: official browser authorization. Green key: API-key access.
Purple document/arrow: credential import. These are workflow symbols, not platform logos.

Project mark: user-supplied `Penrose Triangle in Three Tones.png`.
`frontend/public/project-icon.png` is a centered 512px export with outer transparent
padding cropped. Original colors and artwork are retained. `favicon.svg` embeds
that raster export for the existing SVG route; it is not a vector redraw.
`favicon.ico` provides 16/32/48/64px variants.

`api-key.svg`: key path copied unchanged from Sub2API `frontend/src/components/icons/Icon.vue`, revision `ba81c7fd758e425d67f856d601147ef0c5263d3f` (Wei-Shaw and contributors, LGPL-3.0). Retains the 24px viewBox and 1.5px stroke; only the application color is local. License texts: `backend/internal/responsescompat/LICENSE` and `COPYING`.
